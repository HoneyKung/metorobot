# METO vision — กล้องขั้น 2 (คอมเป็นคนดูภาพ)

กล้อง XIAO ESP32S3 Sense ในหัวหุ่นส่งภาพผ่าน WiFi มาที่คอม (ฮอตสปอตมือถือเดียวกับหุ่น `NNNYTAN`)
คอมทำ 3 อย่าง แล้วสั่งหุ่นผ่าน `/run` เดิม **ไม่ต้องแก้เฟิร์มแวร์หลัก RoboPCA9685**

| คอมเห็น | ส่งไปหุ่น |
|---|---|
| หน้าคนที่ลงทะเบียนไว้ (เจ้าของ) | `/run?cmd=emo:H;emo:B;` ยิ้มแล้วเขิน · คนเดิมทักซ้ำได้ทุก 60 วิ |
| คน (person) | `/run?cmd=yaw:<องศา>;` หันหัวไปหา · อ่าน `yaw` จาก `/state` ก่อน · ถ้าหุ่นกำลังหันตามหน้าเองอยู่ (`faceSeen=1`) คอมจะไม่แย่ง |
| ขวด / แก้ว (bottle / cup) | ไม่สั่งหุ่น · เก็บตำแหน่งไว้ให้บล็อก "ไปหยิบ" ถามทีหลังที่ `http://localhost:8765/objects` และไฟล์ `latest_objects.json` |

ตำแหน่งของที่รายงาน: `x`,`y` = −100..100 (แบบเดียวกับบรรทัด F ของกล้อง) · `w` = กว้างกี่ % ของภาพ (ใหญ่ = ใกล้)
· `bearing_deg` = ของอยู่ที่มุมกี่องศาจากหน้าหุ่น (+ = ซ้ายหุ่น เหมือน `yaw`)

## ติดตั้ง (ครั้งเดียว)

```
py -3 -m pip install ultralytics
```

โมเดล (yolov8n.pt, YuNet, SFace) ดาวน์โหลดลง `models\` เองตอนรันครั้งแรก (ตอนนี้มีครบแล้ว)

## ใช้งาน

เปิด PowerShell ที่โฟลเดอร์นี้ก่อน

```
cd "G:\My Drive\METTO\Code\RoboBlock\tools\meto_vision"
```

1. ทดสอบไม่ต้องมีหุ่น/กล้อง: `py -3 meto_vision.py test --imgsz 640 --conf 0.3` → ภาพผลอยู่ใน `test_out\`
2. ลองกับเว็บแคมคอม ไม่สั่งหุ่น: `py -3 meto_vision.py run --source 0 --dry-run`
3. ลงทะเบียนหน้าเจ้าของ (ถ่าย 5 รูป ห่างกันรูปละ 1 วิ ต้องมีหน้าเดียวในภาพ):
   `py -3 meto_vision.py enroll --name farm`
   หรือจากรูปที่มีอยู่: `py -3 meto_vision.py enroll --name farm --folder "D:\รูป\farm"`
   ใช้ชื่อภาษาอังกฤษ (หน้าต่างภาพเขียนไทยไม่ได้) · ลงชื่อเดิมซ้ำ = แทนของเก่า
4. ใช้จริงกับหุ่น: `py -3 meto_vision.py run`
   ในหน้าต่าง: `q` = ออก · `p` = หยุด/เริ่มสั่งหุ่น

## ตั้งค่า `config.json`

- `robot_url` ค่าเริ่ม `http://MDTrobot.local` (mDNS ไม่ขึ้น → ใส่ IP หุ่นจาก Serial เช่น `http://192.168.43.50`)
- `camera_url` ค่าเริ่ม `http://metocam.local:81/stream` (หรือ `http://<IP กล้อง>:81/stream`)
- `camera_mode` คอมสั่งกล้องตอนเริ่ม: `both` = กล้องยังตรวจหน้าบนบอร์ด+ส่งภาพ 240×240 · `stream` = ภาพ VGA ชัดกว่า แต่ **พักตัวตรวจหน้าบนบอร์ด** (หุ่นไม่หันตามหน้าเอง คอมหันให้แทน) — ตอนใช้ `stream` ตั้ง `look_hfov_deg` เป็น ~60
- `greet_names` ว่าง = ทักทุกคนที่ลงทะเบียน · `face_match_threshold` สูงขึ้น = จำเข้มขึ้น
- `yolo_imgsz` 320 เร็ว (ของใกล้หุ่นเห็นชัดอยู่แล้ว) · 640 เห็นของเล็ก/ไกล แต่ช้าลง ~3 เท่า
- `look_x_sign` หัวหันหนีคน → ตั้ง `-1`

## กล้อง (FullCam v9)

ตั้ง `#define CAM_WIFI 1` (ค่าเริ่ม) · `0` = เหมือน v8 ทุกอย่าง · กล้องต่อ WiFi แบบไม่รอ ต่อไม่ได้ก็ตรวจหน้าบนบอร์ดต่อตามเดิม
- `http://metocam.local/` ดูภาพในเบราว์เซอร์ · `/status` · `/capture` · `/mode?m=detect|both|stream`
- Serial Monitor (USB 115200): `D` detect · `B` both · `W` stream · `I` สถานะ/IP

ทำไมไม่ได้ VGA พร้อมตรวจหน้าบนบอร์ด: เซนเซอร์ส่งได้ทีละรูปแบบ ตัวตรวจหน้า ESP-DL ต้องใช้ RGB565 240×240
โหมด `both` จึงบีบภาพ 240×240 เดียวกันเป็น JPEG ด้วยซอฟต์แวร์ (ทำเฉพาะตอนมีคนดู) · อยากได้ VGA ต้องใช้โหมด `stream`

## ยังต้องลองกับของจริง

FPS กล้องจริง, ภาพสลับด้านหรือไม่ (`look_x_sign`), มุมมองจริง (`look_hfov_deg`), การจำหน้าในแสงห้องจริง
