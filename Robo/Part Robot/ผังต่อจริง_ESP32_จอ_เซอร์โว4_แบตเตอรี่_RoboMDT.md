# ผังต่อจริง RoboMDT: ESP32 + จอ + Servo 4 ตัว + แบตเตอรี่

ฉบับนี้ไม่ต่อมอเตอร์ล้อ TB6612, PCA9685, XIAO หรือเซนเซอร์ ใช้ ESP32 สั่ง Servo โดยตรง และใช้เบรดบอร์ดเป็นจุดเสียบสายชั่วคราว

## 1. รางไฟบนเบรดบอร์ด

```text
รางแดงบน      = RAW+ จากแบตหลังสวิตช์ 6.0–8.4V
รางน้ำเงินบน   = GND จาก BMS P-
รางแดงล่าง     = SERVO 5.0V จาก XH-M401 OUT+
รางน้ำเงินล่าง  = GND ร่วม
```

เชื่อมรางน้ำเงินบนกับรางน้ำเงินล่างหนึ่งเส้น ห้ามเชื่อมรางแดงบนกับรางแดงล่าง

## 2. แบตเตอรี่ BMS และสวิตช์สองขา

```text
BMS P+ → สวิตช์ขาใดก็ได้
สวิตช์อีกขา → รางแดงบน RAW+
BMS P- → รางน้ำเงินบน GND
```

สวิตช์สองขาไม่มีขั้วบวกหรือลบ ขาสองข้างสลับกันได้ ไม่ต้องนำ P- ผ่านสวิตช์

## 3. LM2596 สำหรับ ESP32

| LM2596 | ต่อไปยัง |
|---|---|
| `IN+` | รางแดงบน RAW+ |
| `IN-` | รางน้ำเงินบน GND |
| `OUT+` | ESP32 `V5/VIN` โดยตรง |
| `OUT-` | ESP32 `GND` |

ตั้งเอาต์พุต LM2596 เป็น 5.00V ก่อนเสียบ ESP32

## 4. XH-M401 สำหรับ Servo

| XH-M401 | ต่อไปยัง |
|---|---|
| `IN+` | รางแดงบน RAW+ |
| `IN-` | รางน้ำเงินบน GND |
| `OUT+` | รางแดงล่าง SERVO 5V |
| `OUT-` | รางน้ำเงินล่าง GND |

ตั้งเอาต์พุตเป็น 5.0V ก่อนเสียบ Servo ห้ามเชื่อม SERVO 5V เข้าขา `5V`, `VIN` หรือ `3V3` ของ ESP32

XH-M401 ที่ใช้ XL4016 ต้องการไฟเข้าอย่างน้อยประมาณ 8V จึงใช้กับแบต 2S ได้เพียงช่วงที่แบตเต็มใกล้ 8.4V หากเอาต์พุตต่ำกว่า 4.8V ให้หยุด

## 5. Servo ต่อเข้า ESP32 โดยตรง

| Servo | สายสัญญาณต่อ ESP32 |
|---|---:|
| MG996R แขนซ้าย | GPIO25 |
| MG996R แขนขวา | GPIO26 |
| SG90 หัวหันซ้าย–ขวา | GPIO27 |
| SG90 หัวก้ม–เงย | GPIO32 |

สายของ Servo ทุกตัว:

```text
แดง             → รางแดงล่าง SERVO 5V
น้ำตาล/ดำ        → รางน้ำเงินล่าง GND
ส้ม/เหลือง/ขาว   → GPIO ตามตาราง
```

ตรวจสีสายกับฉลากของ Servo จริงก่อนเสียบ เพราะบางยี่ห้อใช้สีไม่เหมือนกัน

## 6. จอแดง ST7789 240×320 (ใช้งานแนวนอน 320×240)

| ขาจอ | ESP32 |
|---|---:|
| `VCC` | `3V3` |
| `GND` | GND |
| `CS` | GPIO5 |
| `RESET/RST` | GPIO4 |
| `DC` | GPIO2 |
| `SDI/MOSI` | GPIO23 |
| `SCK/CLK` | GPIO18 |
| `SDO/MISO` | ไม่ต่อ ตั้ง `MISO=-1` |
| `LED/BL` | 3V3 ผ่าน R 100Ω หากบอร์ดไม่มีตัวต้านทานจำกัดกระแส |

ขา Touch `T_CLK`, `T_CS`, `T_DIN`, `T_DO`, `T_IRQ` ยังไม่ต่อ ถ้าแฟลช ESP32 ไม่เข้า ให้ถอดสายจอ `DC` จาก GPIO2 ชั่วคราว

## 7. ภาพรวม

```text
แบต 2S → BMS P+ → สวิตช์ → RAW+ ┬→ LM2596 5V → ESP32 VIN
                                  └→ XH-M401 5V → ราง Servo → Servo 4 ตัว

BMS P- ─────────────────────────────→ GND ร่วมทุกส่วน

ESP32 ─→ TFT: CLK18 MOSI23 CS5 DC2 RST4
ESP32 ─→ Servo signal: 25, 26, 27, 32
```

## 8. ลำดับเปิดครั้งแรก

1. ยังไม่เสียบ ESP32 จอ หรือ Servo
2. เปิดสวิตช์ วัดราง RAW และตรวจขั้วบวก/ลบ
3. ตั้ง LM2596 เป็น 5.00V และ XH-M401 เป็น 5.0V
4. ปิดสวิตช์ เสียบ ESP32 และจอ แล้วเปิดทดสอบจอ
5. ปิดสวิตช์ เสียบ SG90 ทีละตัวและทดสอบทีละตัว
6. ปิดสวิตช์ เสียบ MG996R ทีละตัว โดยประคองแขนไม่ให้ติดขัด
7. เมื่อเสียบครบ ให้สั่งเคลื่อนช้า ๆ ทีละ Servo ห้ามกระชากพร้อมกันสี่ตัว

ปิดสวิตช์ก่อนเสียบหรือถอดสายทุกครั้ง หาก Servo สั่น, ESP32 รีบูต, 5V ต่ำกว่า 4.8V, เบรดบอร์ดหรือหัวสายเริ่มอุ่น ให้หยุดทันที
