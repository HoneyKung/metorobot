## 🔧 ระบบขั้วต่อ JST-XH 2.54mm

### ทำไมเลือก JST-XH?

| คุณสมบัติ | ข้อดี |
|---------|------|
| Pitch 2.54mm | ตรงกับ Pin Header ของ ESP32/PCA9685 |
| มี Key (ร่อง) | **กลับด้านไม่ได้** → เสียบผิดไม่พัง |
| มี Latch (ล็อก) | ไม่หลุดเองเวลาหุ่นเคลื่อนที่ |
| ราคาถูก | หาง่ายในไทย < 5 บาท/เส้น |
| Pre-Crimped | ซื้อสำเร็จรูป ไม่ต้องย้ำเอง |

### ระบบ Color-Code

| สี | ความหมาย | จำนวน Pin | ใช้ตรงไหน |
|:---:|---------|:---:|---------|
| 🔴 **แดง** | ไฟ 5V (Power) | 2-pin | LM2596 → ESP32, LM2596 → PCA9685 |
| 🟠 **ส้ม** | ไฟ 7.4V (Battery) | 2-pin | BMS → TB6612 VM |
| 🔵 **น้ำเงิน** | I2C Bus (Data) | 4-pin | ESP32 ↔ PCA9685 ↔ VL53L0X ↔ MPR121 |
| 🟢 **เขียว** | Motor Control | 3+4 pin | ESP32 → TB6612 |
| 🟡 **เหลือง** | TFT Display (SPI) | 7-pin | ESP32 → TFT 2.8" |
| ⚪ **ขาว** | Camera Serial | 3-pin | XIAO → ESP32 |
| 🟤 **น้ำตาล** | IR Sensor | 3-pin ×2 | ESP32 ← IR-L, IR-R |
| ⚫ **ดำ** | Motor + Encoder | 6+5 pin | TB6612 → TT Motor |
| 🟣 **ม่วง** | Encoder Signal | 4+3 pin | Motor Encoder → ESP32 |

> **กฎสำหรับเด็ก:** สีเดียวกัน = เสียบด้วยกัน / ขนาด JST ต่างกัน = เสียบผิดตำแหน่งไม่ได้

### 1. ESP32 DevKit V1 — 38 Pin

#### ฝั่งซ้าย (v3: ย้าย I2C มา + ลบ Motor ออก)

```
    ┌─── 🟤 IR-L [JST 3-pin] ──────────────────────────────────┐
    │ D15: Signal (IR ซ้าย)                                     │
    │ 3V3: VCC                                                  │
    │ GND: GND                                                  │
    └───────────────────────────────────────────────────────────┘

    ┌─── ⚪ CAM [JST 3-pin] ────────────────────────────────────┐
    │ D2:  TX (ESP32 → กล้อง XIAO)                              │
    │ D35: RX (กล้อง XIAO → ESP32)  ← Input Only               │
    │ GND: GND                                                  │
    └───────────────────────────────────────────────────────────┘

    ┌─── 🟡 TFT [JST 7-pin] ──────────────────────────────────┐
    │ D4:  CS   — Chip Select                                  │
    │ D16: RST  — Reset                                        │
    │ D17: DC   — Data/Command                                 │
    │ D5:  MOSI — SPI Data (VSPI)                              │
    │ D18: SCLK — SPI Clock (VSPI)                             │
    │ D19: BL   — Backlight                                    │
    │ GND: GND                                                 │
    └──────────────────────────────────────────────────────────┘

    ┌─── 🔵 I2C [JST 4-pin] ─────────────── 🆕 v3 ────────────┐
    │ D21: SDA   — I2C Data                                    │
    │ D22: SCL   — I2C Clock                                   │
    │ 3V3: VCC   — 3.3V Logic                                  │
    │ GND: GND                                                  │
    │                                                           │
    │ ↳ ต่อไป: PCA9685 (0x40) → VL53L0X (0x29) → MPR121 (0x5A)│
    └───────────────────────────────────────────────────────────┘

    ┌─── 🔴 PWR [Screw Terminal 2-pin] ────────────────────────┐
    │ VIN: 5V (จาก LM2596)                                     │
    │ GND: GND                                                  │
    │ ★ [100µF 16V] บัดกรีคร่อม VIN–GND                         │
    │ ★ [10µF Ceramic] บัดกรีคร่อม 3V3–GND                      │
    └───────────────────────────────────────────────────────────┘
```

### 2. PCA9685 — 16-Channel PWM Servo Driver

```
╔════════════════════════════════════════════════════════════════╗
║  PCA9685 — ตัวขยายขา Servo (I2C Address: 0x40)                ║
╠════════════════════════════════════════════════════════════════╣
║                                                                ║
║  ── I2C Input (จาก ESP32) ──────────────────────────────────  ║
║  🔵 JST 4-pin "I2C"                                           ║
║  │ SDA ← D21 (ESP32 ฝั่งซ้าย)  🆕 v3                          ║
║  │ SCL ← D22 (ESP32 ฝั่งซ้าย)  🆕 v3                          ║
║  │ VCC ← 3.3V                                                 ║
║  │ GND ← GND                                                  ║
║                                                                ║
║  ── Servo Power (แยกจาก Logic!) ────────────────────────────  ║
║  🔴 Screw Terminal "SRV-PWR"                                   ║
║  │ V+  ← 5V จาก LM2596                                        ║
║  │ GND ← Common GND                                           ║
║                                                                ║
║  ── Capacitor (บัดกรีล่วงหน้า) ─────────────────────────────  ║
║  │ [1000µF 16V] ← ตำแหน่ง C2 (มีรูเจาะบนบอร์ด)               ║
║  │ [100µF 16V]  ← ข้าง Screw Terminal                         ║
║                                                                ║
║  ── Servo Output (เสียบสายเซอร์โวตรงๆ) ─────────────────────  ║
║                                                                ║
║  CH0  ──→  SG90     หัวซ้าย-ขวา     "SV-HEAD"                 ║
║  CH1  ──→  SG90     คอขึ้น-ลง       "SV-NECK"                 ║
║  CH2  ──→  MG996R   แขนซ้าย         "SV-ARM-L"                ║
║  CH3  ──→  MG996R   แขนขวา          "SV-ARM-R"                ║
║  CH4  ──→  MG90S    มือซ้าย         "SV-HAND-L"               ║
║  CH5  ──→  MG90S    มือขวา          "SV-HAND-R"               ║
║  CH6  ──→  [ว่าง]                                              ║
║  ...                                                           ║
║  CH15 ──→  [ว่าง]                   ═══ เหลือ 10 ช่อง! ═══    ║
║                                                                ║
║  ── วิธีเสียบเซอร์โว ───────────────────────────────────────  ║
║                                                                ║
║     PCA9685 Header:        สาย Servo มาตรฐาน:                 ║
║     ┌───┬───┬───┐          ┌──────────────────┐                ║
║     │GND│VCC│SIG│   ←──→   │ ดำ │ แดง │ ส้ม  │                ║
║     └───┴───┴───┘          └──────────────────┘                ║
║           ↑                                                    ║
║     เสียบตรง! ไม่ต้องตัดสาย ไม่ต้องบัดกรี                     ║
║                                                                ║
╚════════════════════════════════════════════════════════════════╝
```

### หมายเหตุ: TT Motor + Encoder (6 สายต่อตัว!)

```
TT Motor + Hall Effect Encoder (13PPR, 1:90)
═════════════════════════════════════════════

   Motor Body           Encoder Board
  ┌────────┐          ┌──────────────┐
  │        ├──────────┤ Hall Sensor  │
  │   DC   │          │  A     B     │
  │  Motor │          │ VCC   GND    │
  └──┬──┬──┘          └──┬──┬──┬──┬──┘
     │  │                │  │  │  │
     ▼  ▼                ▼  ▼  ▼  ▼
   M+  M−            Enc_A Enc_B VCC GND
     │  │                │    │    │   │
     │  │                │    │    │   │
  ───┼──┼────────────────┼────┼────┼───┼───
  TB6612 (A01/A02)    ESP32 GPIO   3V3  GND
```

**Encoder ซ้าย = Full Quadrature** (2 ช่อง A+B) → D25 + D26 (ฝั่งขวา 🆕v3)  
**Encoder ขวา = Single Channel** (1 ช่อง A) → D39 (ฝั่งขวา, input-only OK 🆕v3)  

> ทำไม single channel พอ?
> - ทิศทางรู้จาก motor command (IN3/IN4) อยู่แล้ว
> - 13PPR × 90 gear = 1,170 pulse/รอบ — ละเอียดเกินพอ
> - PID speed control ใช้ 1 ช่องก็โอเค
> - ประหยัด pin = ไม่ต้องใช้ D39 (Input Only, ไม่มี pull-up)

## ⚠️ ข้อควรระวัง

1. **อย่าเสียบสายตอนเปิดสวิตช์** — ปิดสวิตช์ก่อนเสียบ/ถอดทุกครั้ง
2. **JST มีทิศทาง** — ถ้าเสียบไม่เข้า **อย่าดัน** แสดงว่ากลับด้าน
3. **Servo กินไฟมาก** — MG996R stall ~2.5A → ต้องมี Cap 1000µF ที่ PCA9685
4. **LM2596 ร้อน** — เว้นช่องระบายอากาศที่ผนังชั้น 2
5. **Encoder VCC ใช้ 3.3V** — ห้ามต่อ 5V เข้า Encoder (จะเผา Hall sensor)
6. **D12 เป็น Strapping Pin** — ใช้ได้ แต่ตอน boot ห้ามมีแรงดัน pull-up/down ที่ pin นี้

## 🆚 เปรียบเทียบระบบเก่า vs ใหม่

| | เก่า | ใหม่ |
|---|:---:|:---:|
| **Servo ต่อ** | GPIO ตรง (กิน 5 pin) | **PCA9685** (กิน 2 pin I2C) ⬇️ |
| **I2C** | ไม่มี | **D25/D26** ✅ |
| **Encoder** | ไม่มี | **D33/D32 (ซ้าย) + D27 (ขวา)** ✅ |
| **Pin ใช้** | 20 pin | **21 pin** (เพิ่ม 1 แต่ได้มากกว่า) |
| **Pin ว่าง** | 6 pin (รวม D39/D36 ห่วย) | **4 pin (D36/D39/RX/TX สำรอง)** |
| **สาย Servo** | ต่อ GPIO ตรง (ยุ่ง) | **เสียบ PCA9685 Header ตรง** ✅ |
| **ขั้วต่อ** | Jumper wire ทั่วไป | **JST-XH Color-Coded** ✅ |
| **Cap กันไฟกระชาก** | ไม่มี | **6 ตัวทุกจุดสำคัญ** ✅ |
| **เด็กประกอบเอง** | ยาก | **ง่ายเหมือนเลโก้** ✅ |

---

> 📝 **สรุป:** ระบบใหม่ใช้ JST-XH 2.54mm ทั้งหมด 23 สาย แยกสี 9 สี กลุ่ม pin ที่เปลี่ยนอยู่ฝั่งขวาติดกัน 5 ตัว (D25-D27, D32-D33) ไม่ใช้ D39/D36 เลย Servo เสียบ PCA9685 ตรง Capacitor 6 ตัวบัดกรีล่วงหน้าโดยครู เด็กทำแค่เสียบ JST ตามสี
