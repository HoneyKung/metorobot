# แผนต่อจอและแขน RoboMDT แบบแบตเตอรี่และเบรดบอร์ด

ฉบับเร่งด่วนสำหรับสาธิตวันศุกร์ ตัดระบบเดิน มอเตอร์ล้อ TB6612 และกล้อง XIAO ออกทั้งหมด เหลือ ESP32, TFT, PCA9685 และ Servo แขน 4 ตัว

## 1. อุปกรณ์ที่ต่อ

- แบตเตอรี่ 2S และ BMS
- สวิตช์หลัก
- LM2596 สำหรับ ESP32 และ TFT
- XH-M401 สำหรับไฟ Servo ชั่วคราว
- ESP32, TFT, PCA9685
- Servo แขน CH0–CH3 เท่านั้น

ไม่ต้องต่อ TB6612, มอเตอร์ล้อ, XIAO, Servo คอ CH4–CH5 หรือเซนเซอร์

## 2. รางเบรดบอร์ด

```text
รางแดงบน      = RAW+ หลังสวิตช์ 6.0–8.4V
รางน้ำเงินบน   = BMS P-/GND
รางแดงล่าง     = 5.0V จาก LM2596 OUT+
รางน้ำเงินล่าง  = GND จาก LM2596 OUT-
```

เชื่อมรางน้ำเงินบนกับน้ำเงินล่างหนึ่งเส้น ห้ามเชื่อมรางแดงบนกับรางแดงล่าง

## 3. ตารางต่อไฟ

| จาก | ไป |
|---|---|
| BMS `P+` | สวิตช์เข้า |
| สวิตช์ออก | รางแดงบน RAW+ |
| BMS `P-` | รางน้ำเงินบน GND |
| LM2596 `IN+ / IN-` | ราง RAW+ / GND |
| LM2596 `OUT+ / OUT-` | ราง 5V ล่าง / GND ล่าง |
| ESP32 `V5/VIN` | ราง 5V ล่าง |
| ESP32 `GND` | ราง GND |
| XH-M401 `IN+ / IN-` | ราง RAW+ / GND ใกล้จุดรับไฟ |
| XH-M401 `OUT+ / OUT-` | PCA9685 ขั้วสกรู `V+ / GND` โดยตรง |
| PCA9685 `VCC` | ESP32 `3V3` |
| PCA9685 Logic `GND` | GND ร่วม |
| PCA9685 `SDA / SCL` | ESP32 GPIO21 / GPIO22 |
| PCA9685 `OE` | GND |

XH-M401 ใช้ชั่วคราวได้เฉพาะตอนแบต 2S ชาร์จเต็มใกล้ 8.4V เพราะวงจร XL4016 ระบุแรงดันทำงานขั้นต่ำ 8V หากตั้ง 5.0V ไม่ได้หรือเอาต์พุตตกต่ำกว่า 4.8V ให้หยุด ไม่ใช้งานต่อ

## 4. TFT

| TFT | ESP32 |
|---|---:|
| `GND` | GND |
| `SCK/CLK` | GPIO18 |
| `MOSI/SDI` | GPIO23 |
| `MISO/SDO` | ไม่ต่อ ตั้ง `MISO=-1` |
| `CS` | GPIO5 |
| `DC/RS` | GPIO2 |
| `RST` | GPIO4 |
| `VCC` | ใช้แรงดันเดิมที่เคยเปิดจอรุ่นนี้ได้ ห้ามเดาสลับ 3.3V/5V |

ถ้าแฟลช USB ไม่เข้า ให้ถอดสาย TFT `DC` ออกจาก GPIO2 ชั่วคราว

## 5. Servo แขน

| PCA9685 | อุปกรณ์ |
|---:|---|
| CH0 | MG996R แขนซ้ายข้อโคน |
| CH1 | MG90S แขนซ้ายข้อไหล่ |
| CH2 | MG996R แขนขวาข้อโคน |
| CH3 | MG90S แขนขวาข้อไหล่ |
| CH4–CH5 | ยังไม่เสียบ |

เสียบ Servo เข้ากับ PCA9685 โดยตรง เริ่มจากถอดแขนออกจากกลไกหรือประคองไม่ให้ติดขัด ทดสอบทีละตัวก่อน แล้วจึงเสียบครบ 4 ตัว แต่ให้เคลื่อนทีละข้อต่อ ห้ามสั่งทุกตัวกระชากพร้อมกัน

## 6. วิธีถอดชั้นโดยไม่ตัดสาย

- ชุด `POWER-IN`: BMS/สวิตช์ → ราง RAW
- ชุด `LM-IN` และ `LM-OUT`: LM2596 → ราง
- ชุด `XH-IN`: XH-M401 → ราง RAW
- ชุด `XH-OUT`: XH-M401 → ขั้วสกรู PCA9685
- ชุด `I2C`: 3V3, GND, SDA21, SCL22
- ชุด `TFT`: GND, CLK18, MOSI23, CS5, DC2, RST4 และ VCC

ติดป้ายชื่อทั้งสองปลาย เมื่อถอดชั้นให้ปิดสวิตช์ก่อน แล้วดึงเป็นชุด ไม่ต้องตัดสายหรือบัดกรีข้ามชั้น

## 7. ลำดับเปิดครั้งแรก

1. ยังไม่เสียบ ESP32, TFT, PCA9685 หรือ Servo
2. วัด BMS `P+` ถึง `P-` และตรวจขั้วบวก/ลบ
3. เปิดสวิตช์ ตั้ง LM2596 เป็น 5.00V
4. ใช้แบตเต็ม ตั้ง XH-M401 เป็น 5.0V แล้วตรวจว่ายังคง 5.0V
5. ปิดสวิตช์ เสียบ ESP32 และ TFT แล้วเปิดทดสอบจอก่อน
6. ปิดสวิตช์ ต่อ PCA9685 โดยยังไม่เสียบ Servo แล้วตรวจ I2C `0x40`
7. ปิดสวิตช์ เสียบ Servo ทีละตัว เปิดและทดสอบทีละช่อง
8. เมื่อครบ 4 ตัว ทดลองท่าช้า ๆ ทีละข้อต่อ

หยุดทันทีหากแรงดัน Servo ต่ำกว่า 4.8V, Servo สั่นผิดปกติ, ESP32 รีบูต, สายหรือเบรดบอร์ดเริ่มอุ่น มีกลิ่นไหม้ ควัน หรือประกายไฟ

## 8. ขอบเขตการสาธิต

จอเปิดพร้อมกับแขนได้ และเสียบสายให้ถอดแยกชั้นได้ แต่ต้นแบบยังไม่มีฟิวส์และใช้เบรดบอร์ดในทางไฟกำลังชั่วคราว จึงให้สาธิตช่วงสั้นภายใต้การดูแล เคลื่อนแขนทีละข้อต่อ และไม่ให้ Servo ค้างชนปลายระยะ
