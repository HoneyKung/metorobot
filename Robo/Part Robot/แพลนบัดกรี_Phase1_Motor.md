# แผนต่อด่วน RoboMDT แบบแบตเตอรี่และเบรดบอร์ด

ฉบับชั่วคราวสำหรับอัปเดตวันศุกร์ ใช้ pin map ใหม่ แต่ใช้เบรดบอร์ดเป็นจุดเสียบถอดสายตามชั้น ห้ามใช้เป็นแบบถาวรหรือให้เด็กใช้งานเอง เพราะยังไม่มีฟิวส์และหน้าสัมผัสเบรดบอร์ดไม่เหมาะกับกระแสสูงต่อเนื่อง

## เป้าหมาย

- ESP32, TFT และ XIAO เปิดพร้อมกัน
- มอเตอร์สองตัวเดินได้
- PCA9685 ควบคุม Servo ได้
- ถอดแต่ละชั้นด้วยการดึงชุดสายออก ไม่ต้องตัดสาย
- Encoder, TCRT5000, Touch, VL53L0X, MPR121 และ SD ยังไม่ต่อ

## 1. กำหนดรางเบรดบอร์ด

ใช้เบรดบอร์ดเพียงครึ่งเดียวก่อน เพราะรางยาวบางรุ่นขาดตรงกลาง

```text
รางแดงด้านบน     = RAW+ จากแบตหลังสวิตช์ 6.0–8.4V  ← ใช้เป็นจุดอ้างอิง/วัดเท่านั้น
รางน้ำเงินด้านบน  = RAW-/GND จาก BMS P-

รางแดงด้านล่าง    = LOGIC 5.0V จาก LM2596 OUT+
รางน้ำเงินด้านล่าง = GND จาก LM2596 OUT-
```

เชื่อมรางน้ำเงินบนกับรางน้ำเงินล่างหนึ่งเส้นเพื่อให้ GND ร่วมกัน

ห้ามเชื่อมรางแดงบนกับรางแดงล่าง เพราะรางบนเป็นแรงดันแบตสูงสุด 8.4V แต่รางล่างต้องเป็น 5.0V เท่านั้น

> 🔴 **ห้ามให้ไฟกำลังไหลผ่านหน้าสัมผัสเบรดบอร์ด — สำคัญที่สุดในไฟล์นี้**
>
> รูปแบบการสั่งงานจริงคือ **MG996R สองตัวขยับพร้อมกัน + MG90S สองตัวขยับพร้อมกัน + มอเตอร์ล้อสองตัววิ่งพร้อมกัน** กระแสที่ไหลออกจาก `RAW+` ในจังหวะนั้นคือ:
>
> | กิ่ง | กระแสที่ดึงจาก RAW+ |
> |---|---:|
> | ราง Servo (ผ่าน XH-M401) | ~2.0A |
> | มอเตอร์ล้อ 2 ตัว (ผ่าน TB6612 VM) | ~1.0–2.0A |
> | ราง Logic (ผ่าน LM2596) | ~0.4A |
> | **รวม** | **~3.4–4.4A** |
>
> หน้าสัมผัสเบรดบอร์ดรับได้จริงราว **1–2A ต่อจุด** ถ้าปล่อย 4A ผ่านราง จะเกิดแรงดันตกที่หน้าสัมผัส ความร้อนสะสม สปริงในรางล้าถาวร และหลุดเป็นจังหวะจน ESP32 รีบูตกลางเดโม
>
> **วิธีต่อที่ถูก:** ทำจุดพักไฟหลังสวิตช์ (เทอร์มินัลบล็อกหรือจุดบัดกรีรวมหุ้มท่อหด) แล้วเดินสาย 20AWG **แยกออกจากจุดนั้นตรงๆ** ไปสามกิ่ง
>
> | กิ่ง | เดินจาก | ห้าม |
> |---|---|---|
> | TB6612 `VM` | จุดพักไฟโดยตรง | ผ่านเบรดบอร์ด |
> | XH-M401 `IN+` | จุดพักไฟโดยตรง | ผ่านเบรดบอร์ด |
> | LM2596 `IN+` | จุดพักไฟโดยตรง | ผ่านเบรดบอร์ด |
>
> `GND` ของทั้งสามกิ่งก็เดินกลับจุดพักไฟด้วยสาย 20AWG เช่นกัน ส่วนรางน้ำเงินบนของเบรดบอร์ดต่อเป็น GND ร่วมด้วยสายเส้นเดียว เพื่อให้วัดแรงดันอ้างอิงได้ ไม่ใช่ให้กระแสกำลังไหลผ่าน
>
> เบรดบอร์ดในแผนนี้เหลือหน้าที่แค่ **แจกไฟ Logic 5V, แถว 3V3 และสายสัญญาณ** ซึ่งรวมกันไม่ถึง 0.5A จึงปลอดภัย

## 2. แบตเตอรี่ 2S และ BMS

| จาก | ไป |
|---|---|
| ลบก้อนที่ 1 | BMS `B-` |
| บวกก้อนที่ 1 | ลบก้อนที่ 2 |
| จุดกลางสองก้อน | BMS `B1/BM` ตามตัวอักษรบนบอร์ด |
| บวกก้อนที่ 2 | BMS `B+` |
| BMS `P+` | ขาเข้าของสวิตช์ |
| ขาออกสวิตช์ | **จุดพักไฟ `RAW+`** (เทอร์มินัลบล็อก) |
| BMS `P-` | **จุดพักไฟ `RAW-/GND`** |
| จุดพักไฟ `RAW+` | รางแดงบนเบรดบอร์ด — สายเส้นเดียวสำหรับวัดอ้างอิงเท่านั้น |
| จุดพักไฟ `RAW-` | รางน้ำเงินบนเบรดบอร์ด — GND ร่วม |

ต่อ B- ก่อน จุดกลางถัดมา และ B+ เป็นลำดับสุดท้าย จากนั้นวัด P+ ถึง P- ก่อนเสียบลงเบรดบอร์ด

## 3. LM2596 สำหรับ Logic

ก่อนต่อโหลด ให้เสียบเฉพาะ IN แล้วปรับ OUT เป็น 5.00V

| LM2596 | เบรดบอร์ด |
|---|---|
| `IN+` | **จุดพักไฟหลังสวิตช์โดยตรง — ไม่ผ่านเบรดบอร์ด** |
| `IN-` | **จุดพักไฟ GND โดยตรง — ไม่ผ่านเบรดบอร์ด** |
| `OUT+` | รางแดงล่าง LOGIC 5V |
| `OUT-` | รางน้ำเงินล่าง GND |

จากราง Logic 5V จ่ายให้:

- ESP32 ขา `V5/VIN`
- XIAO ขา `5V`
- TFT ขา VCC เฉพาะเมื่อยืนยันว่าบอร์ดรับ 5V หากยังไม่ยืนยันให้เริ่ม 3.3V

## 4. XH-M401 สำหรับ Servo

| XH-M401 | ต่อกับ |
|---|---|
| `IN+` | **จุดพักไฟหลังสวิตช์โดยตรง 20AWG — ไม่ผ่านเบรดบอร์ด** |
| `IN-` | **จุดพักไฟ GND โดยตรง 20AWG — ไม่ผ่านเบรดบอร์ด** |
| `OUT+` | PCA9685 ขั้วสกรู `V+` โดยตรง ไม่ผ่านเบรดบอร์ด |
| `OUT-` | PCA9685 ขั้วสกรู `GND` โดยตรง ไม่ผ่านเบรดบอร์ด |

ปรับ XH-M401 เป็น 5.0V ก่อนเสียบ Servo และใช้แบตชาร์จเต็มใกล้ 8.4V

**ลำดับทดสอบ:** เสียบทีละตัวเพื่อยืนยันทิศทางและตำแหน่งกึ่งกลางก่อน จากนั้นจึงทดสอบ **กลุ่ม A พร้อมกัน** ซึ่งเป็นรูปแบบใช้งานจริง

| กลุ่ม | เซอร์โว | สั่งพร้อมกัน |
|---|---|---|
| **A** | MG996R ×2 (CH0, CH2) + MG90S ×2 (CH1, CH3) | ✅ พร้อมกันได้ และวิ่งพร้อมมอเตอร์ล้อได้ |
| **B** | SG90 คอ/หัว (CH4, CH5) | แยกจังหวะจากกลุ่ม A |

> ⚠️ **XH-M401 อยู่นอกสเปกของชิปบนแบต 2S** ชิป **XL4016** ระบุอินพุตขั้นต่ำ **8V** แต่แพ็ก 2S คือ 6.0–8.4V จึงอยู่ในสเปกเฉพาะตอนชาร์จเต็มใหม่ๆ ใช้ได้แบบทดลองเท่านั้น ไม่รับประกัน
>
> ยิ่งกลุ่ม A ขยับพร้อมมอเตอร์ล้อ แบตจะยุบลงอีก 0.5–0.9V ทำให้อินพุตของ XH-M401 ต่ำกว่าสเปกชัดเจน **ต้องวัดเอาต์พุตขณะกลุ่ม A ขยับจริงพร้อมล้อหมุน** ไม่ใช่ตอนอยู่เฉยๆ
>
> หยุดทันทีถ้าเอาต์พุตต่ำกว่า 4.8V, Servo สั่น/ครางค้าง หรือ ESP32 รีบูต

## 5. ESP32 และราง 3.3V

| ESP32 | ต่อกับ |
|---|---|
| `V5/VIN` | รางแดงล่าง LOGIC 5V |
| `GND` | รางน้ำเงินล่าง GND |
| `3V3` | แถวว่างหนึ่งแถวบนเบรดบอร์ด ตั้งชื่อว่า `3V3` |

ใช้แถว `3V3` แจกเฉพาะไฟ Logic ให้ TB6612 `VCC/STBY` และ PCA9685 `VCC` ห้ามต่อเข้าราง 5V

## 6. TB6612 และมอเตอร์

| TB6612 | ต่อกับ |
|---|---|
| `VM` | **จุดพักไฟหลังสวิตช์โดยตรง 20AWG — ไม่ผ่านเบรดบอร์ด** |
| `GND` | **จุดพักไฟ GND โดยตรง 20AWG — ไม่ผ่านเบรดบอร์ด** |
| `VCC` | แถว 3V3 จาก ESP32 |
| `STBY` | แถว 3V3 จาก ESP32 |
| `PWMA` | GPIO25 |
| `AIN1` | GPIO26 |
| `AIN2` | GPIO27 |
| `PWMB` | GPIO32 |
| `BIN1` | GPIO33 |
| `BIN2` | GPIO14 |
| `AO1/AO2` | มอเตอร์ซ้ายโดยตรง ไม่ผ่านเบรดบอร์ด |
| `BO1/BO2` | มอเตอร์ขวาโดยตรง ไม่ผ่านเบรดบอร์ด |

TB6612 มี pull-down ภายใน คืนนี้ไม่ต้องเพิ่ม R 10kΩ สี่ตัว เริ่ม PWM 80–100 และยังไม่เกิน 180/255

**คาปาซิเตอร์ — ต้องใส่ เพราะกลุ่ม A ขยับพร้อมมอเตอร์:** `1000–2200µF 16V` คร่อม `V+`/`GND` ที่ขั้วสกรู PCA9685 และ `470–1000µF 16V` คร่อม `VM`/`GND` ที่ TB6612 ตัวนี้คือสิ่งที่รับกระแสกระชากแทนบั๊ก ระวังขั้วให้ถูก

## 7. PCA9685 และ Servo

| PCA9685 | ต่อกับ |
|---|---|
| `VCC` | แถว 3V3 จาก ESP32 |
| Logic `GND` | ราง GND |
| `SDA` | GPIO21 |
| `SCL` | GPIO22 |
| `OE` | GND |
| ขั้วสกรู `V+` | XH-M401 OUT+ 5.0V โดยตรง |
| ขั้วสกรู `GND` | XH-M401 OUT- โดยตรง |

| ช่อง | Servo |
|---:|---|
| CH0 | MG996R แขนซ้ายข้อโคน |
| CH1 | MG90S แขนซ้ายข้อไหล่ |
| CH2 | MG996R แขนขวาข้อโคน |
| CH3 | MG90S แขนขวาข้อไหล่ |
| CH4 | SG90 คอหันซ้าย–ขวา |
| CH5 | SG90 ฐานหัวก้ม–เงย |

เสียบ Servo เข้ากับ PCA9685 โดยตรง ทำให้ถอดชั้นแขนได้ด้วยการดึงหัว Servo ออกทีละตัว

## 8. กล้อง XIAO

| XIAO | ต่อกับ |
|---|---|
| `5V` | รางแดงล่าง LOGIC 5V |
| `GND` | ราง GND |
| `D6/GPIO43 TX` | ESP32 GPIO16 RX2 |

เฟิร์มแวร์ ESP32 ใช้ `Serial2.begin(9600, SERIAL_8N1, 16, -1)` เพียงจุดเดียว

## 9. TFT

| TFT | ต่อกับ ESP32 |
|---|---:|
| `GND` | GND |
| `SCK/CLK` | GPIO18 |
| `MOSI/SDI` | GPIO23 |
| `MISO/SDO` | ไม่ต่อ ตั้ง `MISO=-1` |
| `CS` | GPIO5 |
| `DC/RS` | GPIO2 |
| `RST` | GPIO4 |
| `LED/BL` | 3.3V ถ้าบอร์ดมี R จำกัดกระแส |

ถ้าแฟลช USB ไม่เข้า ให้ถอดสาย `DC` จาก GPIO2 ชั่วคราว

## 10. ชุดสายที่ดึงออกเมื่อถอดชั้น

### ชั้น 1: แบต BMS TB6612 และมอเตอร์

ดึงชุด Motor Control 6 เส้นออกจาก ESP32:

```text
GPIO25, GPIO26, GPIO27, GPIO32, GPIO33, GPIO14
```

จากนั้นคลายสาย `VM`/`GND` ของ TB6612 ออกจากจุดพักไฟ ชั้น 1 จะแยกออกได้

### ชั้น 2: LM2596 และ XH-M401

คลายสาย LM2596 `IN+/IN-` และ XH-M401 `IN+/IN-` ออกจากจุดพักไฟ ดึง LM2596 `OUT+/OUT-` ออกจากรางล่าง จากนั้นถอดสาย XH `OUT` สองเส้นที่ PCA9685

### ชั้น 3: ESP32 และเบรดบอร์ด

เป็นจุดกลางของสายทั้งหมด เมื่อถอดชั้นอื่นให้ดึงสายเป็นชุดตามชื่อ ไม่ต้องตัดหรือแกะรอยบัดกรี

### ชั้น 4: PCA9685 และ Servo

ดึง I2C `SDA/SCL/GND`, สายไฟ Servo จาก XH สองเส้น และหัว Servo แต่ละตัว

### ชั้น 5: TFT และ XIAO

ดึงชุด TFT และชุด XIAO ออกจาก ESP32/เบรดบอร์ด

ติดป้ายกระดาษที่ปลายสายว่า `MOTOR`, `XH-IN`, `XH-OUT`, `LM-IN`, `LM-OUT`, `I2C`, `TFT`, `CAM`

## 11. ลำดับทดสอบ

1. ยังไม่เสียบ ESP32, XIAO, TFT, มอเตอร์ หรือ Servo
2. วัด BMS P+ ถึง P-
3. เปิดสวิตช์สั้นๆ วัดที่จุดพักไฟ `RAW+`/`RAW-`
4. ตั้ง LM2596 5.00V และ XH-M401 5.0V
5. ปิดสวิตช์ เสียบ ESP32 แล้วแฟลชโค้ด pin map ใหม่ผ่าน USB
6. ถอด USB เปิดแบต ทดสอบ ESP32 อย่างเดียว
7. ต่อ TB6612 โดยยังไม่ต่อมอเตอร์
8. ยกล้อพ้นพื้น ต่อมอเตอร์ทีละตัว
9. ต่อ PCA9685 โดยยังไม่มี Servo สแกน I2C ต้องพบ `0x40`
10. เสียบ Servo ทีละตัวโดยยังไม่ใส่กลไก
11. ต่อ XIAO และ TFT เป็นลำดับสุดท้าย
12. ทดลองระบบรวมช่วงสั้น แล้วตรวจรางเบรดบอร์ดและหัว Dupontว่าร้อนหรือไม่

หยุดทันทีหากรางเบรดบอร์ดหรือหัวสายอุ่นขึ้น สายร้อน มีกลิ่นไหม้ ควัน ประกายซ้ำ แรงดัน 5V ต่ำกว่า 4.8V หรือ ESP32 รีบูต

## 12. Pin map ใหม่

```text
Motor A  PWMA=25 AIN1=26 AIN2=27
Motor B  PWMB=32 BIN1=33 BIN2=14
I2C      SDA=21 SCL=22 PCA9685=0x40
TFT      SCLK=18 MOSI=23 MISO=-1 CS=5 DC=2 RST=4
Camera   RX=16 TX=ไม่ใช้ Baud=9600
```

แผนนี้อนุญาตให้ทดสอบทุกระบบ แต่ไม่รับประกันการขยับมอเตอร์และ Servo ทุกตัวพร้อมกันผ่านหน้าสัมผัสเบรดบอร์ด ให้สาธิตการทำงานทีละกลุ่มและตรวจความร้อนตลอด

## 12. ของที่ต้องซื้อเปลี่ยน XH-M401 — ไม่ต้องเป็น UBEC

ปัญหาของ XH-M401 มีข้อเดียวคือชิป **XL4016 มีพื้นอินพุตขั้นต่ำ 8V** ซึ่งสูงกว่าแบต 2S ของเรา **บั๊กราคาถูกเกือบทุกตัวในตลาดไม่มีปัญหานี้** จึงไม่จำเป็นต้องเป็น UBEC

**สเปกที่ต้องการจริง:** อินพุตครอบคลุม **6.0–8.4V** · เอาต์พุตปรับได้ถึง **5.0V** · จ่ายได้ **≥3A ต่อเนื่อง** (5A สบายกว่า)

ที่มาของตัวเลข 3A คือกลุ่ม A ขยับพร้อมกัน: MG996R ×2 ≈ 1.2–2.0A + MG90S ×2 ≈ 0.3–0.5A + SG90 ×2 ค้างตำแหน่ง ≈ 0.2A รวม **~1.7–2.7A** ต่อเนื่อง และกระชากช่วงออกตัวสูงกว่านั้น

| ตัวเลือก | ช่วงอินพุต | กระแส | ราคาโดยประมาณ | ความเห็น |
|---|---|---:|---:|---|
| **XL4005 5A** | 5–32V | 5A | ~60–90฿ | **แนะนำ** หัวเหลือจริงสำหรับกลุ่ม A + มอเตอร์ |
| LM2596 ตัวที่สอง | 4.5–40V | 3A ป้าย / ~2A จริง | ~30–45฿ | ถูกสุดและคุ้นวิธีตั้งแล้ว แต่ตึงสำหรับกลุ่ม A ต้องระวังความร้อน |
