# สเปกอุปกรณ์จริงและงบกระแสสำหรับรายงาน RoboMDT

อัปเดต: 30 สิงหาคม 2026  
วัตถุประสงค์: เก็บรุ่นอุปกรณ์ที่ใช้จริง แยกข้อมูลผู้ผลิต ค่าประมาณออกแบบ และค่าที่ต้องวัดจริง เพื่อใช้เขียนเล่มรายงานโดยไม่กล่าวเกินหลักฐาน

## 1. หลักการใช้ข้อมูลในเล่ม

ข้อมูลแต่ละค่าต้องระบุสถานะให้ชัด:

- **ยืนยันจากตัวเลือกสินค้า/ของจริง**: ใช้ระบุชื่อรุ่น จำนวน และลักษณะทางกล
- **สเปกอ้างอิงจากผู้ผลิต**: ใช้อธิบายความสามารถของรุ่นมาตรฐาน แต่ห้ามกล่าวว่าเป็นค่ารับรองของสินค้า generic
- **งบออกแบบ**: ใช้เลือกแหล่งจ่าย สาย ฟิวส์ และ BMS ไม่ใช่ผลการทดลอง
- **ค่าที่วัดจริง**: ใช้เป็นผลทดสอบในเล่มหลังวัดด้วยมิเตอร์หรือ USB power meter

| เซอร์โวหัว/คอ | 2 | SG90 แบบกำหนดตำแหน่ง 180° | ไม่ใช่รุ่นหมุนต่อเนื่อง 360° |

## 3. สเปกเซอร์โวสำหรับรายงาน

### 3.1 MG996R จำนวน 2 ตัว

ตัวเลือกที่ซื้อเป็น MG996R 0–180° เฟืองโลหะ ผู้ผลิต TowerPro ระบุสเปกของรุ่นมาตรฐานไว้ดังนี้:

| รายการ | สเปกอ้างอิง TowerPro |
|---|---:|
| แรงดันใช้งาน | 4.8–6.6V |
| แรงบิดสตอลล์ | 9.4kg·cm ที่ 4.8V; 11kg·cm ที่ 6.0V |
| ความเร็ว | 0.19s/60° ที่ 4.8V; 0.15s/60° ที่ 6.0V |
| กระแส idle | 10mA |
| กระแสหมุนไม่มีโหลด | 170mA |
| กระแสสตอลล์ | 1.4A |
| น้ำหนัก | 55g |
| ขนาด | 40.7×19.7×42.9mm |

ข้อจำกัด: สินค้าที่ซื้อจากหน้าร้านรวมหลายรุ่นและไม่ได้แสดงหลักฐานว่าเป็น TowerPro ของแท้ จึงเขียนในเล่มว่า **“ใช้สเปก TowerPro MG996R เป็นค่าอ้างอิงการออกแบบ”** ไม่ควรเขียนว่าเซอร์โวที่ซื้อกินกระแส 1.4A แน่นอนจนกว่าจะวัด

### 3.2 AEI.th MG90S จำนวน 2 ตัว

สิ่งที่ยืนยันจากสินค้า: MG90S, เฟืองโลหะ, ยี่ห้อ AEI.th จำนวนจริง 2 ตัว

สเปก TowerPro MG90S ใช้เทียบขนาดและสมรรถนะเท่านั้น:

| รายการ | ค่าอ้างอิงรุ่นมาตรฐาน |
|---|---:|
| แรงดันอ้างอิง | 4.8V |
| แรงบิดสตอลล์ | 1.8kg·cm ที่ 4.8V; 2.2kg·cm ที่ 6.6V |
| ความเร็ว | 0.10s/60° ที่ 4.8V; 0.08s/60° ที่ 6.0V |
| น้ำหนัก | 13.4g |
| ขนาด | 22.8×12.2×28.5mm |

หน้าอ้างอิงของ TowerPro ไม่ระบุกระแส และสินค้าจริงเป็น AEI.th จึงไม่ใส่ค่ากระแสสตอลล์เป็น “สเปกจริง” ให้เผื่อ 0.3–1.0A ต่อกลุ่มที่กำลังขยับในการคำนวณเบื้องต้น แล้วแทนด้วยค่าที่วัดจริงภายหลัง

### 3.3 SG90 180° จำนวน 2 ตัว

SG90 ที่ใช้เป็น positional servo 180° ไม่ใช่ continuous rotation สเปกอ้างอิงของ SG90 มาตรฐานคือ 4.8V, แรงบิดสตอลล์ประมาณ 1.8kg·cm, ความเร็วประมาณ 0.12s/60°, น้ำหนัก 9g และเฟือง POM

หน้าสินค้าที่ซื้อไม่ให้ข้อมูลกระแสที่ตรวจสอบย้อนกลับถึงผู้ผลิต จึงไม่อ้างค่ากระแสเป็นค่าจริง ให้ทดสอบทีละตัวและไม่สั่ง SG90 สองตัวเคลื่อนพร้อมชุดยกแขนในโค้ดปกติ

## 4. XIAO ESP32-S3 Sense

บอร์ดที่ใช้จริงคือ XIAO ESP32-S3 Sense ไม่ใช่ ESP32-CAM-MB

| รายการ | สเปกที่ใช้ในรายงาน |
|---|---|
| MCU | ESP32-S3, dual-core, สูงสุด 240MHz |
| หน่วยความจำบนบอร์ดรุ่นอ้างอิง | Flash 8MB และ PSRAM 8MB |
| การสื่อสาร | Wi-Fi 2.4GHz และ Bluetooth LE |
| ขนาดบอร์ด XIAO | ประมาณ 21×17.8mm |
| กล้องที่ใช้ในระบบ | OV2640 |
| อินพุต USB-C | 5V |
| กระแสโหมด webcam ที่ 5V | เฉลี่ยประมาณ 140mA; พีกจับภาพประมาณ 347mA ตามข้อมูล Seeed |
| งบออกแบบที่สงวนให้ชุดกล้อง | สูงสุด 0.6A ที่ 5V เพื่อเผื่อ Wi-Fi, กล้องและพีกเริ่มทำงาน |

ค่า 0.6A เป็นงบออกแบบ ไม่ใช่กระแสที่กินตลอดเวลา

## 5. จอ TFT SPI 2.8 นิ้ว

ยืนยันชนิดจากค่าที่คอมไพล์ใช้งานจริงของ TFT_eSPI เวอร์ชัน 2.5.43 แล้ว ไม่ยึดชื่อรวมหลายรุ่นบนหน้าร้าน:

| ค่า | การตั้งค่าจริง |
|---|---|
| Display controller | `ST7789_DRIVER` |
| ความละเอียด native แนวตั้ง | 240×320 พิกเซล (`TFT_WIDTH` ค่าเริ่มต้น 240, `TFT_HEIGHT 320`) |
| แนวใช้งานใน Robo.ino | `tft.setRotation(1)` จึงเป็น 320×240 พิกเซล |
| ลำดับสี | `TFT_RGB_ORDER TFT_BGR` |
| SPI clock | 27MHz |
| MISO | `-1` ไม่ต่อ |
| MOSI / SCLK / CS / DC / RST | GPIO5 / GPIO18 / GPIO4 / GPIO17 / GPIO16 |

`User_Setup_Select.h` เลือก `User_Setup.h` และในไฟล์นั้นเปิด driver เพียง ST7789 ตัวเลือก driver อื่นถูก comment ไว้ จึงให้ระบุในเล่มว่า **“จอ TFT LCD สี 2.8 นิ้ว คอนโทรลเลอร์ ST7789 อินเทอร์เฟซ SPI ความละเอียด 240×320 พิกเซล ใช้งานแนวนอน 320×240 พิกเซล”**

งบกระแสเบื้องต้นสำหรับจอพร้อม backlight ยังคงใช้ 0.1–0.2A ที่ 5V จนกว่าจะวัดจริง หมายเหตุ: `User_Setup.h` มี `TFT_BL=GPIO19` แต่ผังสายบางฉบับต่อ LED/BL ค้างกับ 3.3V จึงห้ามใช้ GPIO19 เป็นข้อสรุปการต่อสายจนกว่าจะตรวจสายจริง

## 6. งบกระแสที่แก้ใหม่

เงื่อนไขใช้งานสูงตามแผน:

- MG996R สองตัวขยับพร้อมกัน
- มอเตอร์ล้อสองตัวทำงานพร้อมกัน
- MG90S และ SG90 ไม่ขยับพร้อมชุดยกแขน แต่ยังค้างตำแหน่ง
- ESP32 หลัก, XIAO พร้อมกล้อง, TFT, PCA9685 และเซนเซอร์เปิดอยู่

### 6.1 ราง Servo 5V

| สถานการณ์ | กระแสที่ใช้วางแผน |
|---|---:|
| เปิดค้าง/ขยับเบา | 0.5–1.2A |
| MG996R สองตัวทำงานตามแผน | 1.3–2.4A |
| งบใช้งานสูงสำหรับคำนวณ | 2.5A |
| พีกสั้นที่แหล่งจ่ายควรรองรับ | ประมาณ 5A หรือมากกว่าชั่วขณะ |

ดังนั้น BEC 5V 5A ต่อเนื่องที่มีพิกัด burst สูงกว่า 5A ยังเหมาะสม ไม่จำเป็นต้องซื้อ 8–10A หากโค้ดสั่งทีละกลุ่มและหยุดเมื่อกลไกติด

### 6.2 ราง Logic 5V

| โหลด | งบกระแส |
|---|---:|
| ESP32 DevKit หลัก | 0.25–0.50A |
| XIAO ESP32-S3 Sense + กล้อง | 0.14A เฉลี่ย, เผื่อพีก 0.35–0.60A |
| TFT 2.8 นิ้ว + backlight | 0.10–0.20A จนกว่าจะวัด |
| PCA9685 ฝั่งลอจิกและเซนเซอร์ | 0.05–0.15A |
| งบรวมที่ใช้เลือกแหล่งจ่าย | 1.0A; ช่วงเผื่อ 0.6–1.2A |

LM2596 ที่ตั้ง 5.0V ใช้กับรางนี้ได้ แต่ต้องทดสอบว่าแรงดันไม่ตกเมื่อ XIAO เปิดกล้องและ Wi-Fi พร้อมจอ

### 6.3 กระแสจากแบตเตอรี่ 2S

ใช้แบต 7.4V และประสิทธิภาพตัวแปลง 85%:

- Servo 5V 2.5A ดึงจาก BUS ประมาณ `12.5 / (7.4 × 0.85) = 1.99A`
- Logic 5V 1.0A ดึงจาก BUS ประมาณ `5 / (7.4 × 0.85) = 0.80A`
- มอเตอร์ล้อดึงจาก BUS ประมาณ 0.6–1.6A ระหว่างวิ่งรับน้ำหนัก

ผลรวมใช้งานสูงตามแผนประมาณ **3.4–4.4A จากแบตเตอรี่** ช่วงเผื่อจากความไม่แน่นอนประมาณ **3.1–4.6A** ส่วนกรณี servo rail ขึ้นถึง 5A พร้อมมอเตอร์ใกล้สตอลล์และลอจิกเต็ม อาจแตะประมาณ **7.4A ชั่วคราว**

ผลต่อการเลือกอุปกรณ์:

- ฟิวส์หลัก 7.5A ยังสมเหตุผล แต่ถ้าขาดต้องหาสาเหตุ ห้ามเปลี่ยนเป็นค่ามากขึ้นทันที
- BMS 2S 8A ต่อเนื่องและพีกสูงกว่า 8A เพียงพอสำหรับรูปแบบใช้งานนี้
- สายและขั้วต่อ BUS หลักควรรองรับอย่างน้อย 10A
- TB6612FNG ยังเหมาะกับมอเตอร์ 1:90 จำนวน 2 ตัว

## 7. สิ่งที่ควรลงในเล่มรายงาน

ควรนำข้อมูลนี้ลงเล่ม แต่แยกตำแหน่งดังนี้:

- **บทที่ 3 อุปกรณ์และการออกแบบ**: ตารางชื่อรุ่น จำนวน แรงดัน แรงบิด ขนาด หน้าที่ และงบกระแส
- **บทที่ 3 การออกแบบระบบไฟ**: สูตรแปลงกำลังและผลรวม 3.4–4.4A พร้อมเหตุผลที่เลือก 5V 5A, BMS 8A และฟิวส์ 7.5A
- **บทผลการทดลอง**: กระแสที่วัดจริง แรงดันตก อุณหภูมิ และเวลาทำงาน ห้ามนำค่าคาดการณ์ไปเขียนเป็นผลทดลอง
- **ภาคผนวก**: ลิงก์สินค้า ภาพรุ่นจริง และตารางวัดรายตัว
