# ส่วนที่ 1: 🔋 ระบบถ่าน (ต้องบัดกรี)

ถ่าน 1 ก้อน = 3.7V ไม่พอ → ต้องต่อ 2 ก้อน **อนุกรม** = 7.4V

> **รางถ่าน BH-18650x2-M เป็นรางเปล่า** ไม่มีสายมาเลย  
> ต้องบัดกรีสาย 20AWG เองทั้งหมด

### รางถ่านเปล่ามี 4 แท็บโลหะ — ไม่มีสปริง ไม่มีสาย ไม่มีอะไรเชื่อมกันเลย

```
รางถ่าน BH-18650x2-M (มองจากด้านบน)
ไม่มีสปริง มีแค่แท็บโลหะแบน 4 ชิ้น

         ด้านหน้า
   ┌─────────────────────┐
   │  [แท็บ+]   [แท็บ−]  │     ← แท็บ 4 ชิ้น ไม่เชื่อมกัน
   │                     │
   │  ╔══════╗ ╔══════╗  │
   │  ║ถ่าน#1║ ║ถ่าน#2║  │     ← ถ่านวางสลับหัว
   │  ║ +  − ║ ║ −  + ║  │
   │  ╚══════╝ ╚══════╝  │
   │                     │
   │  [แท็บ−]   [แท็บ+]  │
   └─────────────────────┘
         ด้านหลัง
```

| แท็บ | ตำแหน่ง | ขั้ว | ของถ่านก้อนไหน |
|:---:|:---:|:---:|:---:|
| A | หน้า-ซ้าย | ⊕ (+) | ก้อน #1 |
| B | หน้า-ขวา | ⊖ (−) | ก้อน #2 |
| C | หลัง-ซ้าย | ⊖ (−) | ก้อน #1 |
| D | หลัง-ขวา | ⊕ (+) | ก้อน #2 |

## ขั้นที่ 1: บัดกรีเดินสายบนรางถ่าน (อนุกรม)

**อนุกรม = เดินสายจาก ⊖ ของก้อน#1 ไปหา ⊕ ของก้อน#2**

```
วิธีต่ออนุกรม:

  ถ่าน#1              ถ่าน#2
  ⊕ ────── ⊖  ──สาย──  ⊕ ────── ⊖
  │              │              │
  │         เดินสาย 20AWG       │
  │         (แท็บ C → แท็บ D)   │
  │              │              │
  ▼              ▼              ▼
 แท็บ A      แท็บ C+D         แท็บ B
 🔴 B+       ⚪ BM            ⚫ B−
(8.4V)    (จุดกลาง)          (GND)
```

### ต้องบัดกรี 4 จุด + เดินสาย 3 เส้น:

| ทำอะไร | บัดกรีที่แท็บ | สายสีอะไร | ชื่อสาย | หมายเหตุ |
|:---:|:---:|:---:|:---:|---------|
| 1. เดินสาย 20AWG สั้น จากแท็บ C ไปแท็บ D | **C** (หลัง-ซ้าย, ก้อน#1 ⊖) → **D** (หลัง-ขวา, ก้อน#2 ⊕) | — | — | **ทำให้เป็นอนุกรม** บัดกรี 2 จุด |
| 2. ต่อสายขาวยาวออกจากจุด C หรือ D | **C** หรือ **D** (จุดที่เพิ่งเชื่อม) | ⚪ ขาว | **BM** | จุดกลางสำหรับ BMS Balance |
| 3. ต่อสายแดงยาวออกจากแท็บ A | **A** (หน้า-ซ้าย, ก้อน#1 ⊕) | 🔴 แดง | **B+** | ไฟ + ของแบต (8.4V เต็ม) |
| 4. ต่อสายดำยาวออกจากแท็บ B | **B** (หน้า-ขวา, ก้อน#2 ⊖) | ⚫ ดำ | **B−** | ไฟ − ของแบต (GND) |

**ผลลัพธ์:** สายออกจากรางถ่าน **3 เส้น** — 🔴 B+, ⚪ BM, ⚫ B−

**เทคนิคบัดกรี:** ขัดแท็บโลหะเบาๆ → ทาฟลักซ์ → วางหัวแร้ง → ป้อนตะกั่ว → วางสาย → กด 2-3 วิ → ดึงเบาๆ ต้องไม่หลุด

**ตรวจสอบ:** ดูด้วยตาว่าตะกั่วเกาะแน่น ไม่มีตะกั่วหยดลัดข้ามแท็บอื่น / ดึงสายแต่ละเส้นต้องไม่หลุด

## ขั้นที่ 2: บัดกรีสาย BMS 2S

BMS มี **3 ขาอินพุต** (ฝั่งแบต) + **2 ขาเอาต์พุต** (ฝั่งโหลด)

### ฝั่งอินพุต — ต่อกับสายจากรางถ่าน (ขั้นที่ 1)

| ขา BMS | บัดกรีกับสายจากขั้นที่ 1 |
|:---:|---------|
| **B+** | 🔴 สายแดง (B+ จากรางถ่าน) |
| **BM** | ⚪ สายขาว (BM จากรางถ่าน) |
| **B−** | ⚫ สายดำ (B− จากรางถ่าน) |

### ฝั่งเอาต์พุต — บัดกรีสาย 20AWG ใหม่ 2 เส้นออกไป

| ขา BMS | สีสาย | ไปที่ (ยังไม่ต่อ รอขั้นถัดไป) |
|:---:|:---:|---------|
| **P+** | 🔴 แดง | → ไปสวิตช์ (ขั้นที่ 3) |
| **P−** | ⚫ ดำ | → GND รวมของระบบทั้งหมด |

---

## ขั้นที่ 3: บัดกรีสวิตช์ KCD-105

สวิตช์มี 2 ขา — คั่นระหว่าง BMS กับระบบทั้งหมด

| ลำดับ | บัดกรีที่ขาสวิตช์ | สาย | มาจากไหน / ไปไหน |
|:---:|:---:|:---:|---------|
| 1 | ขา 1 | 🔴 สายจาก BMS P+ | มาจากขั้นที่ 2 |
| 2 | ขา 2 | 🔴 สาย 20AWG ใหม่ | ออกไป = **V_SW** (ไฟ 7.4V หลังสวิตช์) |

> เปิดสวิตช์ = ไฟผ่าน / ปิดสวิตช์ = ตัดไฟทั้งระบบ

---

## ขั้นที่ 4: บัดกรี LM2596 Buck Converter

LM2596 แปลง 7.4V → 5V สำหรับ ESP32 และ PCA9685

| ขา LM2596 | บัดกรีกับ | มาจากไหน |
|:---:|:---:|---------|
| **IN+** | 🔴 สาย V_SW | สายแดงจากสวิตช์ ขา 2 (ขั้นที่ 3) |
| **IN−** | ⚫ สาย GND | สายดำจาก BMS P− (ขั้นที่ 2) — **ต่อร่วมกัน** |
| **OUT+** | 🔴 สาย 20AWG ใหม่ | ออกไป = ไฟ 5V สำหรับ ESP32 + PCA9685 |
| **OUT−** | ⚫ สาย 20AWG ใหม่ | ออกไป = GND ร่วม — **ต่อร่วมกับ IN−** |

> **⚠️ ปรับ LM2596 ก่อนต่อ ESP32!**  
> ใส่ถ่าน → เปิดสวิตช์ → ดูจอบน LM2596 จะแสดงแรงดัน  
> → หมุน Potentiometer (ตัวเล็กสีน้ำเงิน) ด้วยไขควงจนจอขึ้น **5.0V**  
> → ปรับได้แล้วค่อยต่อสายไป ESP32

## ขั้นที่ 5: บัดกรี CM620 Charger

CM620 ชาร์จถ่านผ่าน USB-C — ต่อ **ขนานกับขาอินพุตของ BMS**

| ขา CM620 | บัดกรี **ร่วม** กับ | หมายเหตุ |
|:---:|---------|---------|
| **B+** | 🔴 สาย B+ เดียวกับที่เข้า BMS B+ | บัดกรีต่อร่วม |
| **BM** | ⚪ สาย BM เดียวกับที่เข้า BMS BM | บัดกรีต่อร่วม |
| **B−** | ⚫ สาย B− เดียวกับที่เข้า BMS B− | บัดกรีต่อร่วม |

> CM620 ต่อ **ขนาน** กับ BMS ฝั่ง input (ไม่ใช่ output)  
> เสียบ USB-C ชาร์จได้โดยไม่ต้องถอดถ่าน

## ขั้นที่ 5.5: สรุปจุดที่ต้องต่อร่วมกัน

สาย GND และสายแบตบางเส้น **ต้องต่อร่วมหลายจุด** ไม่ใช่สายแยกคนละเส้น:

| สาย | จุดที่ต่อร่วม |
|:---:|---------|
| 🔴 **B+** (จากรางถ่าน) | BMS ขา B+ **+** CM620 ขา B+ |
| ⚪ **BM** (จากรางถ่าน) | BMS ขา BM **+** CM620 ขา BM |
| ⚫ **B−** (จากรางถ่าน) | BMS ขา B− **+** CM620 ขา B− |
| ⚫ **GND รวม** (จาก BMS P−) | LM2596 IN− **+** LM2596 OUT− **+** TB6612 GND **+** ESP32 GND |
| 🔴 **V_SW** (จากสวิตช์) | LM2596 IN+ **+** TB6612 VM (แยกสาย 7.4V ตรงไปมอเตอร์) |
| 🔴 **5V** (จาก LM2596 OUT+) | ESP32 VIN **+** PCA9685 V+ |

## ขั้นที่ 8: ต่อ TB6612 ← ESP32 (สั่งมอเตอร์)

> **Pin ใหม่!** Motor 6 pin + Encoder 3 pin อยู่ **ฝั่งขวา ESP32 ทั้งหมด**  
> I2C ย้ายไปฝั่งซ้าย D21/D22 แทน

| ขา TB6612 | ขา ESP32 (ฝั่งขวาทั้งหมด) | หน้าที่ |
|:---:|:---:|---------|
| IN1 | **D13** | Motor A ทิศ 1 |
| IN2 | **D12** | Motor A ทิศ 2 ⚠️ strapping pin |
| PWMA | **D33** | ความเร็ว Motor A |
| IN3 | **D14** | Motor B ทิศ 1 |
| IN4 | **D27** | Motor B ทิศ 2 |
| PWMB | **D32** | ความเร็ว Motor B |

## ขั้นที่ 9: ต่อ TB6612 → Motor (สายออกไปมอเตอร์)

TT Motor มีสายออก 6 เส้น: **2 สายมอเตอร์ + 4 สาย Encoder**

### Motor ซ้าย (6 สาย)

| สายจาก Motor ซ้าย | ไปที่ | หมายเหตุ |
|:---:|:---:|---------|
| M+ (มอเตอร์) | TB6612 ขา **A01** | สาย Dupont |
| M− (มอเตอร์) | TB6612 ขา **A02** | สาย Dupont |
| Enc_A | ESP32 ขา **D25** (ฝั่งขวา) | สัญญาณ Encoder Ch.A |
| Enc_B | ESP32 ขา **D26** (ฝั่งขวา) | สัญญาณ Encoder Ch.B |
| Enc VCC | ESP32 ขา **3V3** | ⚠️ ห้าม 5V! ต่อร่วม rail (+) |
| Enc GND | Breadboard **rail (−)** | GND ร่วม |

### Motor ขวา (5 สาย — single channel)

| สายจาก Motor ขวา | ไปที่ | หมายเหตุ |
|:---:|:---:|---------|
| M+ (มอเตอร์) | TB6612 ขา **B01** | สาย Dupont |
| M− (มอเตอร์) | TB6612 ขา **B02** | สาย Dupont |
| Enc_A | ESP32 ขา **D39** (ฝั่งขวา, input-only ใช้กับ encoder ได้) | สัญญาณ Encoder (ช่องเดียวพอ) |
| Enc VCC | ESP32 ขา **3V3** | ⚠️ ห้าม 5V! ต่อร่วม rail (+) |
| Enc GND | Breadboard **rail (−)** | GND ร่วม |

## ⚠️ ข้อควรระวัง

1. **ปิดสวิตช์ก่อนเสียบ/ถอดสายทุกครั้ง**
2. **Encoder VCC ใช้ 3.3V เท่านั้น** — ต่อ 5V จะเผา Hall sensor
3. **ปรับ LM2596 เป็น 5V ก่อนต่อ ESP32**
4. **ถ่านใส่ถูกขั้ว** — หัวนูนแตะแผ่นแบน / ก้นแบนแตะสปริง
5. **D12 เป็น Strapping Pin** — ตอน upload code ถอดสายออกก่อน
6. **บัดกรีระวังลัดวงจร** — ดูด้วยตาว่าตะกั่วไม่เชื่อมข้ามจุดอื่น
