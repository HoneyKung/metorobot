# ฟอร์มวัดของในหัว — กรอกตัวเลขในช่อง (mm)

ใช้คำนวณความสูงหัว ตำแหน่งแกนก้มเงย และช่องใส่ของ (#158 ข้อ 5) · วัดด้วยเวอร์เนีย · ไม่แน่ใจข้อไหนเว้นว่างได้

## จอ TFT 2.8" (วางแนวนอน)
| วัดอะไร | ค่า |
|---|---|
| บอร์ดจอ กว้าง (ด้านยาว) | |
| บอร์ดจอ สูง (ด้านสั้น) | |
| หนารวม (จากหน้าจอถึงหลังสุด รวมหัวพิน) | |
| พื้นที่ภาพ กว้าง × สูง | |
| ขอบภาพห่างขอบบอร์ด บน / ล่าง / ซ้าย / ขวา | |
| หัวพินออกด้านไหน (ซ้าย/ขวา/บน/ล่าง) และยื่นออกกี่ mm | |
| รูยึดบอร์ด มีไหม · โตเท่าไร · ระยะห่าง | |

## XIAO + กล้อง
| วัดอะไร | ค่า |
|---|---|
| บอร์ด กว้าง × สูง | |
| หนารวม (หน้าเลนส์ถึงหลังบอร์ด) | |
| เลนส์ โตเท่าไร | |
| ศูนย์เลนส์ห่างขอบบอร์ด บน / ซ้าย | |
| พอร์ต USB-C อยู่ขอบไหน | |

## SG90 ก้มเงย (และ SG90 หันคอ ถ้าวัดได้)
| วัดอะไร | ค่า |
|---|---|
| ตัว กว้าง × ยาว × สูง (ไม่รวมหู) | |
| หู: ระยะปลายหูถึงปลายหู · หนา · สูงจากก้น | |
| แกนเฟืองยื่นพ้นผิวบนกี่ mm | |
| ศูนย์แกนห่างขอบตัวด้านใกล้กี่ mm | |
| ฮอร์นที่จะใช้ (แขนเดี่ยว/คู่/วงกลม) · ยาว | |

## MG996R (ชั้น 4) — สำหรับดุมแขน
| วัดอะไร | ค่า |
|---|---|
| แกนเฟืองยื่นพ้นผิวบนกี่ mm | |
| ตัวจริง กว้าง × ยาว × สูง (ที่บวม) | |

## อื่น ๆ ในหัว
| วัดอะไร | ค่า |
|---|---|
| แม่เหล็กหู/หมวก โต × หนา | |
| MPR121 (ถ้ามี) กว้าง × ยาว | |
