### 🔧 วิธีติดตั้ง ESP32 + PCA9685 บน Perfboard

```
ESP32 (ขาตัวผู้บัดกรีมาแล้ว ชี้ลง):

    ESP32 Board
    │ │ │ │ │ │ │ │ │ │ │   ← ขาตัวผู้ (male) ชี้ลง
    ▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼ ▼
   ╔═══════════════════════╗
   ║  Female Header 1×19   ║   ← บัดกรีลง Perfboard
   ╠═══════════════════════╣      ESP32 เสียบลงมา → ถอดได้
   ║     Perfboard         ║
   ║  (บอร์ดไข่ปลา)        ║   ← เดินลายบัดกรีเชื่อมไปยัง
   ║                       ║      JST Header แต่ละกลุ่ม
   ║  [JST🔵] [JST🟢] ... ║   ← JST-XH Header บัดกรีบน Perfboard
   ╚═══════════════════════╝

PCA9685 (ขาตัวผู้บัดกรีมาแล้ว ชี้ขึ้น):

   ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑   ← ขาตัวผู้ (male) ชี้ขึ้น
   ╔═══════════════════════╗
   ║  PCA9685 Board        ║
   ║  Servo Header 3-pin   ║   → สาย Servo มาตรฐาน (Dupont 3-pin)
   ╚═══════════════════════╝      เสียบตรง CH0-CH5 ได้เลย
     ยึดด้วยสกรู/กาว บน Perfboard หรือแผ่นกั้นชั้น

   ⚠️ JST-XH housing หนาเกินไป เสียบ servo header ชนกัน!
      → ใช้สาย Servo/Dupont มาตรฐานเสียบตรงแทน
      → I2C input ใช้สาย Dupont 4-pin หรือบัดกรีตรง
```

| ตำแหน่ง | อุปกรณ์ | ขนาด | วิธีติดตั้ง |
|---------|---------|------|-----------|
| ด้านล่าง (USB หันลง) | ESP32 38-Pin | 28×55×12 mm (กว้าง×ยาว) | เสียบ Female Header บน Perfboard, USB เจาะรูผนังล่าง |
| ด้านบน | PCA9685 | 62.5×25.4×15 mm | ขาชี้ขึ้น, สาย Servo/Dupont เสียบตรง (ไม่ใช่ JST เพราะ housing หนาชนกัน) |
| บน Perfboard | Female Header 1×19 × 2 | 2.54mm pitch | บัดกรีลง Perfboard สำหรับเสียบ ESP32 |
| บน Perfboard | JST-XH Header หลายตัว | 2.54mm pitch | บัดกรีลง Perfboard แยกกลุ่มตามสี |
| บน Perfboard/ESP32 | Cap 100µF + 10µF | — | 100µF คร่อม VIN-GND / 10µF คร่อม 3V3-GND |
| บน PCA9685 | Cap 1000µF + 100µF | — | 1000µF ที่ C2 / 100µF ข้าง V+-GND |

#### 📌 จุดสำคัญ:
- **เหลือ 2 ฮาร์ดแวร์** (ESP32 + PCA9685) + Perfboard เป็นฐาน
- **ESP32 USB หันลง** → เจาะรูผนังด้านล่าง (เหมือน CM620 ที่ชั้น 2)
- **PCA9685 ขาชี้ขึ้น** → สาย Servo/Dupont เสียบตรง CH0-CH5 (ไม่ใช้ JST เพราะ housing หนาชนกัน)
- **Perfboard** เป็นตัวกลาง: รับ Female Header ของ ESP32 + บัดกรี JST Header ทุกกลุ่ม
- ใช้ **JST-XH 2.54mm** ทุกจุดเชื่อมต่อ → ถอดใส่ง่าย ป้องกันเสียบผิด
- PCA9685 รับ Servo ทั้ง 6 ตัว → **ลด GPIO จาก ESP32 ลง 5 pin**
- **ดูรายละเอียดการเสียบสายทั้งหมดที่:** แผนเสียบสายไฟ_RoboMDT.md

### กลุ่มสายไฟ 3 กลุ่ม

#### 🔴 กลุ่ม 1: สายจ่ายไฟ (Power — 20AWG แดง/ดำ)
| จุดเริ่ม | จุดจบ | เส้นทาง |
|---------|-------|---------|
| แบต 18650 | BMS 2S | ชั้น 2 → ภายในชั้น |
| BMS | LM2596 | ชั้น 2 → ภายในชั้น |
| LM2596 (5V out) | ESP32 VIN | ชั้น 2 → **ผนังซ้าย** → ชั้น 3 |
| LM2596 (5V out) | PCA9685 V+ | ชั้น 2 → **ผนังซ้าย** → ชั้น 3 |
| แบต (7.4V direct) | TB6612 VM | ชั้น 2 → **ผนังซ้าย** → ชั้น 3 |

> **เทคนิค:** ใช้ **Bus Bar** หรือ **Terminal Block** ขนาดเล็กที่ชั้น 2 เป็นจุดกระจายไฟ → ลดสายไฟจากชั้น 2 ออกเหลือ 3 คู่เท่านั้น

#### 🔵 กลุ่ม 2: สาย Signal (Servo/Motor/Sensor)
| สาย | จุดเริ่ม | จุดจบ | เส้นทาง |
|-----|---------|-------|---------|
| Servo × 6 | PCA9685 (ชั้น 3) | เซอร์โว (ชั้น 4+5) | **ผนังขวา** ขึ้นชั้น 4 |

## ⚠️ ข้อควรระวัง

1. **MG996R กินกระแสสูง** (stall ~2.5A ต่อตัว) → LM2596 ต้องรับได้ 3A+ → ตรวจสอบ output current
2. **ความร้อน LM2596** → เว้นช่องระบายอากาศที่ผนังชั้น 2
3. **สายพาน 130mm ยาวกว่าตัว** → ต้องออกแบบจุดยึดสายพานที่แข็งแรง
4. **น้ำหนัก** → ชั้นล่าง (แบต + มอเตอร์) หนัก = จุดศูนย์ถ่วงต่ำ ✅ ดี
5. **จอ TFT 69mm สูง** → หัวจะค่อนข้างใหญ่ พิจารณาจอเล็กกว่า (1.8") ถ้าต้องการลดขนาดอีก
6. **คอ SG90 × 2** → รับน้ำหนักหัว (จอ+กล้อง+MPR121) ได้ แต่ไม่ควรเกิน 100g

---

> 📝 **สรุป:** โครงสร้างใหม่ 5 ชั้นช่วยลดความสูงจาก 25cm → ~20cm โดยยัดอุปกรณ์ทุกอย่างอย่างเต็มที่ การแยกสายไฟ 3 กลุ่ม + ช่องเดินสายในผนัง + I2C Daisy-chain ช่วยลดความรกของสายได้มาก PCA9685 เป็น key component ที่ช่วยลด GPIO ที่ต้องใช้จาก ESP32
