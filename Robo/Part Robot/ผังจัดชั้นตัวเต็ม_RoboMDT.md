# ผังจัดชั้นตัวเต็ม RoboMDT

> สำหรับออกแบบโครง 3D ฉบับเต็ม รองรับแบตในตัว, XH-M401, LM2596, มอเตอร์, เซอร์โว 6 ตัว, กล้อง, จอ, VL53L0X และ MPR121
>
> สายสัญญาณใช้ Pin Header/Dupont; สายกำลังใช้สาย 18–20AWG กับขั้วสกรูหรือบัดกรี ไม่ใช้ Dupont

## 1. ภาพรวม 5 ชั้น

```text
ชั้น 5 — หัว
  TFT 2.8" + XIAO ESP32S3 Sense + MPR121 + แผ่นทองแดง
  + SG90 ก้มเงยที่ฐานหัว

ชั้น 4 — คอ แขน และ Servo Control
  MG996R×2 + MG90S×2 + SG90 หันหน้า
  + PCA9685 + VL53L0X

ชั้น 3 — สมองและสัญญาณ
  ESP32 DevKit V1 38-pin + บอร์ดขยาย ESP32 38-pin สำเร็จรูป
  + จุดรวบสายสัญญาณ/Capacitor ฝั่ง logic

ชั้น 2 — แปลงไฟ ชาร์จ และควบคุมไฟ
  XH-M401 + LM2596 + CM620 + สวิตช์ KCD-105
  + ฟิวส์ในอนาคต + จุดแยกไฟ

ชั้น 1 — ฐาน แบต และระบบขับเคลื่อน
  18650×2 + BMS 2S + TT Motor Encoder×2 + TB6612
  + TCRT5000×2 + สายพาน TPU/เฟือง/ล้อตาม
```

## 2. ชั้น 1 — ฐาน แบต และระบบขับเคลื่อน

### อุปกรณ์

| อุปกรณ์ | ตำแหน่งแนะนำ | เหตุผล |
|---|---|---|
| รางถ่าน 18650×2 | กลางค่อนไปด้านหลัง | ของหนักที่สุด ต้องอยู่ต่ำและใกล้กึ่งกลาง |
| BMS 2S 16A | ใกล้รางถ่าน แต่มีแผ่นฉนวนรอง | ทำให้สาย B+/BM/B- สั้นและไม่ต้องวิ่งข้ามชั้น |
| TT Motor Encoder ×2 | ซ้าย/ขวาของฐาน | เพลาตรงกับเฟืองขับสายพาน |
| TB6612FNG | กลางด้านหน้า ระหว่างมอเตอร์ | ทำให้สาย A01/A02/B01/B02 สั้น ลด noise |
| TCRT5000 ×2 | ใต้ฐานด้านหน้าซ้าย/ขวา | ต้องหันลงพื้นและปรับระดับได้ |
| สายพาน TPU + drive sprocket + idler | ภายนอกฐานสองข้าง | idler ต้องเลื่อนตั้งความตึงได้ |

### พื้นที่ที่ต้องเผื่อ

- ใช้ footprint ฐานประมาณเดิม `96 × 135 mm` หรือใหญ่กว่าตามชุดสายพานจริง
- เผื่อช่องถอดแบตโดยไม่ต้องรื้อชั้นบน
- เผื่อฝาครอบ BMS ไม่ให้โลหะ น็อต หรือแบตแตะวงจร
- เผื่อช่องสายกำลังขึ้นชั้น 2 จำนวนอย่างน้อย 4 เส้น: `BUS+`, `BUS-`, สายชาร์จ/สวิตช์ตามผังจริง
- เผื่อช่องสายสัญญาณ encoder และ TCRT5000 ขึ้นชั้น 3 แยกจากสายมอเตอร์
- ทำทางเดินสายมอเตอร์คนละด้านกับสาย encoder

### ความสูงภายในแนะนำ

`40–45 mm` โดยยึดจากรางถ่าน มอเตอร์ จุดต่อสาย และฝาครอบ ไม่ใช่เฉพาะความสูงตัวอุปกรณ์

## 3. ชั้น 2 — ระบบแปลงไฟและชาร์จ

### อุปกรณ์

| อุปกรณ์ | ขนาดอ้างอิง | ตำแหน่งแนะนำ |
|---|---:|---|
| XH-M401 / XL4016 | ประมาณ `61 × 41 × 27 mm` | กลางค่อนไปด้านที่มีช่องลม ฮีตซิงก์ตั้งขึ้น |
| LM2596 | ประมาณ `43 × 21 × 14 mm` | ข้าง XH-M401 แยกพื้นที่ logic |
| CM620 Charger 2S | ประมาณ `30 × 17 × 5 mm` | ชิดผนัง ให้พอร์ต USB โผล่ออกภายนอก |
| KCD-105 | เส้นผ่านศูนย์กลางประมาณ 23mm | ติดผนัง ไม่วางนอนบนพื้นชั้น |
| จุดแยก BUS+/BUS- | ตามวิธีที่เลือก | ใกล้ทางสายจากชั้น 1 |
| ฟิวส์ในอนาคต | เผื่อประมาณ `35 × 15 × 15 mm` | ใกล้สายไฟเข้าก่อนสวิตช์ |

### การวางบนพื้นที่ประมาณ 96 × 112 mm

```text
ด้านหน้า
┌────────────────────────────────────┐
│ [ช่องลม]  XH-M401 61×41   [ช่องลม]│
│          ฮีตซิงก์หงายขึ้น           │
│                                    │
│ LM2596 43×21     CM620 30×17       │
│                  USB → ผนัง         │
│                                    │
│ BUS+/BUS-       พื้นที่เผื่อฟิวส์   │
└────────────────────────────────────┘
   KCD-105 ติดที่ผนังด้านข้าง
```

### พื้นที่และช่องที่ต้องเผื่อ

- XH-M401 ต้องมีช่องว่างรอบฮีตซิงก์อย่างน้อยประมาณ `8–10 mm`
- อย่าวางสายหรือพลาสติกแตะฮีตซิงก์
- ทำช่องลมเข้าด้านล่าง/ข้าง และช่องลมออกเหนือฮีตซิงก์
- เผื่อระยะไขควงสำหรับขั้วสกรูและตัวปรับแรงดัน
- USB ชาร์จต้องเสียบได้โดยไม่ถอดฝาหุ่น
- แยกรูชาร์จออกจากรู USB โปรแกรม ESP32 คนละด้านหรือทำสัญลักษณ์ชัดเจน
- ทำฝาชั้น 2 เปิดซ่อมได้ เพราะเป็นชั้นที่ต้องปรับแรงดันและตรวจความร้อน

### ความสูงภายในแนะนำ

`35–40 mm` เพราะ XH-M401 สูงประมาณ 27mm และต้องเผื่อหัวสาย/การระบายความร้อน

## 4. ชั้น 3 — ESP32 และจุดรวมสายสัญญาณ

### อุปกรณ์

| อุปกรณ์ | ตำแหน่งแนะนำ | หมายเหตุ |
|---|---|---|
| ESP32 DevKit V1 38-pin | กลางชั้น | ใช้บอร์ดจริง 38-pin |
| บอร์ดขยาย ESP32 38-pin สำเร็จรูป | ใต้ ESP32 | เด็กเสียบสายพินได้ ไม่ต้องใช้ perfboard |
| Capacitor ฝั่ง logic | ใกล้ขาไฟของบอร์ดขยาย | ใช้เฉพาะถ้ามีจุดขัน/เสียบที่ปลอดภัย |

### การจัดช่องสาย

```text
ช่องลงชั้น 1: Motor control + Encoder + TCRT5000
ช่องไปชั้น 2: LOGIC-5V + GND
ช่องขึ้นชั้น 4: I2C + Servo signal/อุปกรณ์ส่วนบน
ช่องขึ้นชั้น 5: TFT SPI + Camera Serial/Power
```

- ทำช่องสายอย่างน้อย 2 ฝั่ง: ฝั่งมอเตอร์/encoder และฝั่งจอ/I2C
- USB ESP32 ต้องเข้าถึงจากภายนอกโดยไม่รื้อชั้น
- ต้องมีจุดรัดสายก่อนถึงหัว Dupont ป้องกันแรงดึงลงบนพิน
- ห้ามวาง XH-M401 ในชั้นนี้ เพราะความร้อนและสายกำลังจะอยู่ใกล้ ESP32/encoder มากเกินไป

### ความสูงภายในแนะนำ

วัดจากบอร์ดขยาย ESP32 ของจริง โดยทั่วไปเผื่อ `28–35 mm` รวมหัว Dupont และรัศมีดัดสาย

## 5. ชั้น 4 — แขน คอ PCA9685 และ VL53L0X

### อุปกรณ์

| อุปกรณ์ | ตำแหน่งแนะนำ | หมายเหตุ |
|---|---|---|
| MG996R แขนซ้าย/ขวา | ต้นแขนซ้าย/ขวา | ต้องรับโครงแขน MG90S และวัตถุ จึงเก็บ MG996R ไว้ |
| MG90S ×2 | จุดข้อต่อที่ออกแบบไว้บริเวณหัวไหล่/ข้อแขน | ไม่ได้อยู่ปลายแขน |
| SG90 หันหน้า | กึ่งกลางบนของตัว ยึดใกล้ฐานหัว | คอสั้นช่วยลดโมเมนต์ที่ servo ต้องรับ |
| PCA9685 | กลางค่อนไปด้านหลังหรือใต้ฝาชั้นที่เปิดได้ | อยู่ใกล้ servo ทั้งหมด ทำให้สายสั้น |
| VL53L0X | ด้านหน้าระหว่างแนวแขนตามเรขาคณิตของแบบจริง | เผื่อช่องมอง ห้ามมีโครงบัง |

### พื้นที่ที่ต้องเผื่อ

- PCA9685 ประมาณ `62.5 × 25.4 × 15 mm`
- ต้องเข้าถึง CH0–CH5 ได้หลังประกอบ เพื่อสลับ/ถอด servo
- สาย `SERVO-V+` จาก XH-M401 ขึ้นมาชั้นนี้ใช้สายกำลัง ไม่ใช้ Dupont
- เผื่อ capacitor 1000µF ใกล้ขั้ว V+ ของ PCA9685
- เผื่อการกวาดของแขนทั้งสองข้างและสายที่ขยับตามข้อ ไม่ให้หนีบกับผนัง
- VL53L0X ต้องถอดปรับมุมได้ก่อนล็อกตำแหน่งสุดท้าย

### ความสูงภายในแนะนำ

กำหนดจากกลไกแขนและคอจริง ไม่ใช่จากบอร์ด PCA9685 ควรทำ mock-up ตำแหน่ง servo และช่วงกวาดก่อนปิดแบบ

## 6. ชั้น 5 — หัว

### อุปกรณ์

| อุปกรณ์ | ตำแหน่งแนะนำ | หมายเหตุ |
|---|---|---|
| TFT 2.8" | ด้านหน้าหัว | ใช้พินและไลบรารีชุดเดิมที่เคยทำงาน |
| XIAO ESP32S3 Sense + OV2640 | เหนือจอ/ตำแหน่งเดิม | กล้องต้องไม่มีขอบโครงบัง |
| MPR121 | ด้านบนหรือด้านในฝาหัว | สาย electrode ไปแผ่นทองแดงต้องสั้น |
| แผ่นทองแดงหลายส่วน | บนฝาหัว | รองรับการตรวจลำดับการลูบ |
| SG90 ก้มเงย | ฐานหัว | อยู่คนละตำแหน่งกับ SG90 หันหน้าที่ติดกับตัว |

### พื้นที่ที่ต้องเผื่อ

- ช่องสาย TFT: VCC, GND และ SPI ครบ
- ช่องสาย XIAO: 5V, GND และ TX ไป ESP32
- ช่อง I2C ขึ้น MPR121
- ทำ service loop ที่คอให้หัวหันและก้มเงยได้โดยสายไม่ตึง
- แยกสายกล้อง/TFT ออกจากสาย servo เท่าที่ทำได้
- ทำฝาหัวเปิดได้เพื่อเข้าถึง XIAO และ MPR121

### ความสูงภายในแนะนำ

ใช้จอ 69mm เป็นตัวกำหนดหลัก เผื่อกรอบและสายประมาณ `75–80 mm`

## 7. เส้นทางสายระหว่างชั้น

| จาก → ไป | สาย | ประเภท | วิธีเดิน |
|---|---|---|---|
| ชั้น 1 → 2 | BUS+/BUS- | กำลังสูง | 18–20AWG สั้นและชิดผนัง |
| ชั้น 1 → 3 | Motor control | สัญญาณ | Pin/Dupont แบบรวม housing |
| ชั้น 1 → 3 | Encoder/TCRT5000 | สัญญาณไวต่อ noise | เดินคนละด้านกับสายมอเตอร์ |
| ชั้น 2 → 3 | LOGIC-5V/GND | กำลังต่ำ | สายสองเส้นรวมกัน |
| ชั้น 2 → 4 | SERVO-V+/GND จาก XH-M401 | กำลังสูง | 18–20AWG ห้ามใช้ Dupont |
| ชั้น 3 → 4 | I2C | สัญญาณ | SDA/SCL/GND เดินรวมกัน |
| ชั้น 3 → 5 | TFT SPI | สัญญาณ | เดินเป็นมัดและทำ service loop |
| ชั้น 3 → 5 | XIAO TX/5V/GND | สัญญาณ+ไฟ | เดินเป็นมัดและทำ service loop |
| ชั้น 4 → 5 | MPR121 I2C / SG90 tilt | สัญญาณ | เผื่อการก้มเงย |

## 8. จุดยึดที่ต้องใส่ในโมเดล 3D

- เสารอง/รูน็อตสำหรับ XH-M401, LM2596, CM620, BMS, TB6612, PCA9685 และบอร์ดขยาย ESP32
- ร่องสำหรับเคเบิลไทร์ทุกชั้น
- ช่องสายกำลังแยกจากช่องสายสัญญาณ
- ฝาเปิดซ่อมชั้น 1, 2, 3 และหัว
- ช่องไขควงสำหรับปรับ XH-M401/LM2596 โดยไม่ต้องถอดบอร์ด
- ช่องเสียบ USB ชาร์จ CM620 และ USB โปรแกรม ESP32 คนละตำแหน่ง
- ช่องระบายอากาศรอบ XH-M401
- จุดยึด capacitor 1000µF ไม่ให้ขาสั่นหรือหัก
- จุด strain relief สำหรับสายที่ผ่านคอและข้อแขน
- idler slot สำหรับปรับความตึงสายพาน TPU

## 9. ลำดับประกอบที่ไม่บังคับให้รื้อภายหลัง

1. พิมพ์และประกอบชั้น 1 พร้อมแบต/BMS/TB6612/motor
2. พิมพ์ชั้น 2 เผื่อ XH-M401 เต็มขนาด แม้ตัวบอร์ดยังมาไม่ถึง
3. เดิน BUS+/BUS- และเผื่อสายฟิวส์
4. ติด LM2596 และ XH-M401 แยกหน้าที่กัน
5. ติดบอร์ดขยาย ESP32 ในชั้น 3
6. ประกอบกลไกแขน/คอและ PCA9685 ในชั้น 4
7. ประกอบจอ/XIAO/MPR121 ในหัว
8. ทดสอบแยกทีละชั้นก่อนซ้อนชั้นทั้งหมด

## 10. สิ่งที่ต้องวัดจากของจริงก่อนล็อกไฟล์พิมพ์

- ขนาดจริงและตำแหน่งรูยึด XH-M401 ที่สั่ง
- ขนาดบอร์ดขยาย ESP32 38-pin ที่จะใช้
- ทิศทางและพื้นที่เสียบสาย PCA9685
- รัศมีการกวาดจริงของแขนและคอ
- ตำแหน่งสายออกของ MG996R/MG90S/SG90
- ตำแหน่ง USB ของ CM620, ESP32 และ XIAO
- ขนาด capacitor 1000µF ของจริง
- ขนาดหัวปลั๊กและรัศมีดัดสายกำลัง

ห้ามออกแบบช่องแบบพอดีกับขนาด PCB อย่างเดียว ควรเผื่อขอบอย่างน้อย 2–3mm และเผื่อด้านที่มีขั้วสกรู/หัวสายมากกว่านั้น
