# คู่มือต่อสาย RoboMDT: ล้อ + จอ + กล้อง ด้วย WAGO 221 และ XT30

วันที่: 6 กันยายน 2569  
สถานะ: คู่มือประกอบใหม่จากผัง GPIO ในเอกสารเดิม ยังไม่ใช่ผลตรวจวงจรจริงหรือผลทดสอบเฟิร์มแวร์  
ขอบเขต: แบตเตอรี่ 2S, BMS, ฟิวส์, สวิตช์, XT30, WAGO 221, LM2596, ESP32 DevKit 38 ขา, TB6612FNG, มอเตอร์สองตัว, จอ ST7789 และ XIAO ESP32S3 Sense รวมสายเข้า UBEC เตรียมสำหรับเซอร์โว

## 1. อ่านส่วนนี้ก่อนลงมือ

- ใช้ชื่อขาที่พิมพ์บนบอร์ด ไม่เดาขาจากซ้าย/ขวาหรือสีสายอย่างเดียว
- ตัวแปลงในแผนเดิมชื่อ LM2596 ไม่ใช่ LM2569
- WAGO 221 คือขั้วรวมสาย ส่วน BUS คือชื่อจุดไฟฟ้าที่เราตั้งให้ ไม่ใช่ชื่ออุปกรณ์อีกชิ้น
- XT30 คือปลั๊กไฟสองขั้วสำหรับถอดประกอบ ไม่ใช่ฟิวส์ สวิตช์ ตัวลดแรงดัน หรือวงจรป้องกันกลับขั้วหากบัดกรีผิด
- UBEC ใช้ไฟเซอร์โว ส่วน LM2596 ใช้ไฟควบคุม ห้ามรวม OUT+ ของสองตัวนี้
- งานนี้เริ่มจาก BMS P+/P- ที่ต่อรางถ่านไว้แล้ว ไม่ต้องรื้อสาย B-/BM/B+ หากตรวจถูกต้องแล้ว
- ก่อนบัดกรีหรือเปลี่ยนสาย ให้ถอดถ่านและ USB ทุกเส้น ถอด XT30 และรอคาปาซิเตอร์คายประจุ ตรวจแรงดันก่อนจับจุดต่อ

### สิ่งที่ทราบกับสิ่งที่ยังต้องตรวจ

| รายการ | ข้อมูลสำหรับงานนี้ |
|---|---|
| รางถ่าน → BMS | ผู้ใช้แจ้งว่าต่อแล้ว ต้องวัดยืนยัน P+/P- ก่อนใช้ |
| คาปาซิเตอร์ LM2596 | ผู้ใช้แจ้งว่าบัดกรีแล้ว แผนต้องการบวกที่ OUT+ ลบที่ OUT- |
| จุดบัดกรี TB6612 | ต้องแยกว่าเป็นคาปาซิเตอร์คร่อม VM/GND หรือการเชื่อมขาอื่น ยังไม่ได้ตรวจชิ้นงานจริง |
| สายที่มี | 20AWG แต่ยังไม่ทราบวัสดุ ฉนวน พิกัด และความยาว |
| WAGO | ทราบเพียงซีรีส์ 221 ตารางหลักด้านล่างเลือกแบบ 5 ช่อง 221-415 |
| XT30 | ใช้คู่ที่เสียบเข้ากันได้ ตรวจเครื่องหมาย + / - บนตัวจริง |
| UBEC | ผู้ใช้มีแล้ว แต่ยังไม่มีรุ่นยืนยัน ต้องรับแบต 2S และตั้งไฟออก 5V ได้ |
| จอ | ผังเดิมใช้ ST7789 แต่ VCC 5V และวงจร LED บนโมดูลยังไม่ยืนยัน |
| โค้ด | ต้องตรวจให้ตรง GPIO ในคู่มือนี้ก่อนสั่งงาน ยังไม่ได้แก้หรือทดสอบโค้ดในงานเอกสารนี้ |

## 2. ลำดับอุปกรณ์และหน้าที่ XT30

ลำดับไฟบวก:

```text
BMS P+ → ฟิวส์ใกล้ BMS → XT30 ขั้ว + → สวิตช์ → W1: RAW+
BMS P- ────────────────→ XT30 ขั้ว - ──────────→ W2: RAW-/GND

W1 RAW+ ┬→ LM2596 IN+
        ├→ TB6612 VM
        └→ UBEC IN+

W2 GND  ┬→ LM2596 IN-
        ├→ TB6612 GND
        └→ UBEC IN-

LM2596 OUT+ 5.00V → W3: LOGIC 5V ┬→ ESP32 VIN/5V
                                 └→ ไดโอด → XIAO 5V

LM2596 OUT- → W4: LOGIC GND ┬→ ESP32 GND
                            ├→ XIAO GND
                            └→ ราง GND เบรดบอร์ด → TFT GND

ESP32 3V3 → แถวแจก 3V3 ┬→ TB6612 VCC
                       ├→ TB6612 STBY
                       ├→ TFT VCC (เริ่มทดสอบ 3.3V)
                       └→ ตัวจำกัดกระแส → TFT LED/BL

UBEC OUT+ 5V → PCA9685 V+ เมื่อเริ่มงานเซอร์โว
UBEC OUT-    → PCA9685 GND เมื่อเริ่มงานเซอร์โว
```

### ตำแหน่ง XT30 ที่เลือกใช้

ให้ชุดถอดได้ประกอบด้วย รางถ่าน + BMS + ฟิวส์ + XT30 ฝั่งแหล่งจ่าย ส่วน XT30 อีกครึ่ง สวิตช์ WAGO และบอร์ดต่าง ๆ อยู่ในตัวหุ่น

- ฝั่งแบตใช้หน้าสัมผัสโลหะแบบเบ้ารับที่หลบอยู่ในฉนวน เพื่อลดโอกาสปลายมีไฟแตะกัน
- ฝั่งตัวหุ่นใช้ครึ่งที่เข้าคู่กัน อย่าตัดสินเพศหัวจากรูปทรงพลาสติกอย่างเดียว
- ยึดเครื่องหมาย + และ - ที่ตัวหัวทั้งสองครึ่ง มุมมองด้านบัดกรีกับด้านเสียบกลับซ้าย/ขวากันได้
- บัดกรีสายแดงที่ + และสายดำที่ - แล้วหุ้มท่อหดแยกทุกขา ยึดสายไม่ให้แรงดึงตกที่รอยบัดกรี
- ปิดสวิตช์ก่อนเสียบหรือถอด XT30 ไม่ใช้ดึงปลั๊กตัดมอเตอร์ที่กำลังหมุน
- ถ้ามี XT30 เพียงหนึ่งคู่ ให้ใช้ที่ชุดแบตตามนี้ก่อน ไม่จำเป็นต้องติดทุกกิ่ง
- ไม่ใช้ XT30 สำหรับสายข้อมูลจอหรือกล้อง

รุ่น XT30 มีหลายแบบ ให้ดูพิกัดจากรุ่นจริง ไม่ถือว่าชื่อ “30” รับรองสายและวงจรทั้งหมดที่ 30A [เอกสาร AMASS XT30U-F](https://www.ic-golden.com/wp-content/uploads/2024/09/xt30u-f-datasheet.pdf)

## 3. ตั้งชื่อ WAGO และกำหนดช่อง

ตารางนี้ใช้ WAGO 221-415 แบบรวมสาย 5 ช่อง จำนวน 4 ก้อน ถ้ามีรุ่น 2/3 ช่อง ดูหัวข้อถัดไปก่อนจัดสาย

**ช่องทั้งห้าของ 221-415 ในก้อนเดียวกันเป็นจุดไฟเดียวกัน จึงห้ามใส่บวกและลบในก้อนเดียวเด็ดขาด**

เลขช่อง 1–5 ในคู่มือนี้เป็นเลขที่เราเขียนติดเอง ใช้นับจากซ้ายไปขวาเมื่อมองช่องเสียบสาย ไม่มีช่อง IN/OUT ตายตัว ทุกช่องในก้อนเดียวเทียบเท่ากันทางไฟฟ้า

| ก้อน / ป้าย | ช่อง 1 | ช่อง 2 | ช่อง 3 | ช่อง 4 | ช่อง 5 |
|---|---|---|---|---|---|
| W1: RAW+ แรงดันแบตหลังสวิตช์ | จากสวิตช์ | LM2596 IN+ | TB6612 VM | UBEC IN+ | ว่าง |
| W2: RAW-/GND | จาก XT30 - | LM2596 IN- | TB6612 GND | UBEC IN- | ว่าง |
| W3: LOGIC 5V | LM2596 OUT+ | ESP32 VIN/5V | ไปไดโอดแล้ว XIAO 5V | ว่าง | ว่าง |
| W4: LOGIC GND | LM2596 OUT- | ESP32 GND | XIAO GND | ราง GND เบรดบอร์ด | ว่าง |

LM2596 แบบโมดูลลดแรงดันทั่วไปในแผนนี้ไม่แยกกราวด์ IN-/OUT- ให้ตรวจ continuity ขณะถอดไฟ: W2 กับ W4 ต้องมีกราวด์ร่วมผ่านโมดูล ส่วน W1 กับ W3 ต้องไม่ลัดเข้าหากัน หากโมดูลจริงไม่ตรงแบบนี้ ให้หยุดตรวจรุ่นก่อนต่อโหลด

### วิธีใส่สาย WAGO

1. ตรวจรหัสรุ่นบนตัวจริง ตารางนี้อ้าง 221-415
2. ปอกตามระยะที่ระบุบนตัว/คู่มือ รุ่น 221-415 ระบุ 11 มม.
3. เปิดคันโยก ใส่ทองแดงให้สุดโดยไม่มีเส้นฝอยหลุดออกนอกช่อง แล้วปิดคันโยก
4. หนึ่งสายต่อหนึ่งช่อง ไม่ยัดสายสองเส้นในรูเดียว
5. ปลายฝั่ง WAGO ใช้ทองแดงเปล่าที่จัดเส้นฝอยเรียบร้อย ไม่ต้องชุบตะกั่ว
6. ดึงเบา ๆ ตรวจยึดแน่น และติดป้ายชื่อแรงดันบนแต่ละก้อน

อ้างอิง [WAGO ซีรีส์ 221](https://www.wago.com/gb/products/electrical-interconnections/splicing-connectors-221) และ [ข้อมูลรุ่น 221-415](https://www.wago.com/global/installation-terminal-blocks-and-connectors/splicing-connector-with-levers/p/221-415)

### ถ้ามี WAGO 221 แบบ 3 ช่อง

W1/W2 แต่ละจุดต้องรองรับหนึ่งสายเข้าและสามสายออก ใช้ก้อน 3 ช่องหนึ่งก้อนไม่พอ สามารถต่อสองก้อนด้วยสายเชื่อมหนึ่งเส้นได้:

| จุดไฟ | ก้อน A ช่อง 1 | ก้อน A ช่อง 2 | ก้อน A ช่อง 3 | ก้อน B ช่อง 1 | ก้อน B ช่อง 2 | ก้อน B ช่อง 3 |
|---|---|---|---|---|---|---|
| RAW+ | จากสวิตช์ | TB VM | สายเชื่อมไป B1 | จาก A3 | LM IN+ | UBEC IN+ |
| RAW- | จาก XT30 - | TB GND | สายเชื่อมไป B1 | จาก A3 | LM IN- | UBEC IN- |

สายเชื่อมต้องรับกระแสรวมของกิ่ง LM และ UBEC ได้ ตารางทดแทนนี้ใช้ชื่อจุดไฟเดียวกับ W1/W2 แต่ตำแหน่งช่องต่างจากตาราง 5 ช่อง ห้ามนำเลขช่องสองแบบมาปนกัน

W3 ต้องการ 3 ช่อง ส่วน W4 ต้องการ 4 ช่อง ถ้าใช้แต่รุ่น 3 ช่องทั้งระบบจะใช้รวม 7 ก้อน: W1 สองก้อน, W2 สองก้อน, W3 หนึ่งก้อน, W4 สองก้อน โดย W4 ใช้สายเชื่อมหนึ่งช่องของแต่ละก้อนเช่นเดียวกัน ถ้ามีแบบ 2 ช่อง ให้ใช้เป็นข้อต่อสองสาย ไม่ถือว่าเป็นก้อนกระจายหลายกิ่งได้เอง

## 4. ขนาดสายและฟิวส์

AWG เป็นขนาดตัวนำ ไม่ใช่พิกัดกระแสที่ใช้ได้เหมือนกันทุกสินค้า พิกัดจริงขึ้นกับวัสดุ ฉนวน อุณหภูมิ ความยาว และการมัดรวมสาย

### แบ่งสายเป็นสองชั้นตามกระแสที่ผ่านจริง

| ชั้น | เส้นทาง | ขนาดที่ใช้ | กระแสที่ผ่าน |
|---|---|---|---|
| **สายหลัก** | รางถ่าน → BMS `B-`/`BM`/`B+` → `P+`/`P-` → ฟิวส์ → XT30 → สวิตช์ → W1/W2 | **18AWG** | กระแสรวมทุกกิ่ง ~3.4–4.4A ตอนสั่งพร้อมกัน |
| **สายกิ่ง** | W1/W2 แยกไป LM2596 · TB6612 VM · UBEC และสายมอเตอร์ AO/BO | **20AWG** | กิ่งละ ~0.4–2.0A |

**สายรางถ่านต้องเป็น 18AWG ด้วย** เพราะอยู่บนเส้นทางเดียวกับสายหลักและรับกระแสรวมเท่ากัน สายที่ติดมากับรางถ่านสำเร็จรูปมักเล็กกว่าที่เห็น ถ้าเปลี่ยนได้ให้เปลี่ยน ถ้าเปลี่ยนไม่ได้ให้ตัดสั้นที่สุดแล้วต่อ 18AWG ออกไปแทน และต้องคลำความร้อนที่จุดนี้ตอนทดสอบทุกครั้ง

ห้ามใช้สายเศษที่เหลือจากงานอื่นบนเส้นทางสายหลักโดยไม่ตรวจขนาด เส้นทางนี้คือเส้นทางเดียวที่กระแสทั้งระบบไหลผ่าน

- สายกำลังแต่ละกิ่งและสายมอเตอร์ในแผนใช้ 20AWG ทองแดงขนาดจริง เดินสั้นและต่อแน่น
- สายหลักทั้งบวกและลบต้องรับกระแสรวม รวมถึงสายรางถ่าน สายฐานฟิวส์ และสายสำเร็จรูปที่มากับ XT30
- การเพิ่มกล้องทำให้โหลดมากกว่าชุดล้อกับจอเดิม จึงต้องวัดกระแสและแรงดันจริง ไม่ยืนยันพิกัดจากขนาดสายอย่างเดียว
- UBEC ต่อ IN เตรียมไว้ได้ แต่ยังไม่เสียบเซอร์โวในการทดสอบรอบนี้
- ผังระบบเต็มเคยเผื่อสายหลัก 18AWG และฟิวส์ 7.5A ตารางข้างบนกลับมาใช้ 18AWG ตามนั้นแล้ว แต่ยังไม่ใช่การอนุมัติค่าฟิวส์ 7.5A เพราะยังไม่ทราบรุ่นสายจริง
- ก่อนจ่ายไฟรวม ให้ตรวจพิกัดสาย/ฐานฟิวส์/สวิตช์ที่มี แล้วเลือกฟิวส์ตามชิ้นส่วนที่รับกระแสได้น้อยที่สุด พร้อมพิจารณากระแสเริ่มหมุน ห้ามเพิ่มค่าฟิวส์เพียงเพราะขาด
- ยังไม่กำหนดค่าฟิวส์สุดท้ายในเอกสารนี้ เพราะไม่ทราบรุ่นสายและผลวัดโหลดจริง
- ไม่เสนอให้ใช้สายสองเส้นขนานแทนการตรวจพิกัดสายหลัก

ตัวอย่างความต่างของพิกัด: Belden 8205 เป็น 20AWG แต่ระบุ 3.7A ต่อเส้นที่ 20°C ตัวอย่างนี้แสดงว่าต้องดูรุ่น ไม่ใช่พิกัดของสายผู้ใช้ [ข้อมูล Belden 8205](https://catalog.belden.com/techdata/en/8205_techdata.pdf)

สีสายเป็นเพียงตัวช่วย ให้ติดป้ายปลายทั้งสองด้านด้วย: แดง = ไฟบวก, ดำ = GND, ส้ม = 3.3V, สีอื่น = สัญญาณ อย่าใช้สีแทนการอ่านขา

## 5. ขั้นที่ 1: ตรวจของที่บัดกรีแล้ว

ทำขณะถอดถ่านและ USB:

| จุด | ต้องเป็นอย่างไร |
|---|---|
| BMS B-/BM/B+ | ต่อแพ็กอนุกรม 2S ตามชื่อขาบนบอร์ด จุดกลางอยู่ BM/B1 |
| BMS P+/P- | เป็นฝั่งจ่ายออกของ BMS ไม่ใช้ B+/B- จ่ายโหลดข้ามวงจรป้องกัน |
| คาปาซิเตอร์ LM2596 | ขาบวกต่อ OUT+ ขาลบแถบเครื่องหมายลบต่อ OUT- |
| คาปาซิเตอร์ TB6612 | ขาบวกต่อ VM ขาลบต่อ GND; ตามแผน 470–1000µF 16V |
| TB6612 STBY | ต้องได้รับ 3.3V เพื่อใช้งาน ไม่ต่อ GND |
| TB6612 VM กับ GND | ห้ามมีสายหรือตะกั่วลัดถึงกันโดยตรง คาปาซิเตอร์คร่อมสองจุดนี้ได้ |
| TB6612 VCC กับ STBY | หากผูกกันไว้ ทั้งคู่ต้องไปรับ 3.3V ไม่ใช่แรงดันแบต |

การวัดความต้านทาน/continuity ใช้เฉพาะขณะไม่มีไฟ คาปาซิเตอร์อาจทำให้มิเตอร์ร้องหรือค่าต่ำชั่วครู่ระหว่างชาร์จจากมิเตอร์ อย่าตีความเสียงชั่วครู่เป็นชอร์ตทันที แต่หากค่าต่ำค้างต้องหาสาเหตุก่อนจ่ายไฟ

## 6. ขั้นที่ 2: ต่อแบต ฟิวส์ XT30 สวิตช์ และ WAGO

ยังไม่ใส่ถ่าน ไม่เสียบ XT30 และยังไม่ต่อโหลด

| เลขสาย | จาก | ไป | งานที่ทำ |
|---|---|---|---|
| P01 | BMS P+ | สายเข้าฐานฟิวส์ | สายหลักแดง บัดกรี/ขั้วที่เหมาะสม หุ้มท่อหด |
| P02 | สายออกฐานฟิวส์ | XT30 ฝั่งแบต ขั้ว + | บัดกรี หุ้มท่อหด |
| P03 | BMS P- | XT30 ฝั่งแบต ขั้ว - | สายหลักดำ บัดกรี หุ้มท่อหด |
| P04 | XT30 ฝั่งหุ่น ขั้ว + | สวิตช์ขาที่ 1 | สายหลักแดง |
| P05 | สวิตช์ขาที่ 2 | W1 ช่อง 1 | สายหลักแดง ปลายฝั่ง WAGO ไม่ชุบตะกั่ว |
| P06 | XT30 ฝั่งหุ่น ขั้ว - | W2 ช่อง 1 | สายหลักดำ |

สวิตช์ในแผนเดิมคือ KCD1-105 สองขา เลือกขาใดเป็นเข้า/ออกได้ ถ้าชิ้นจริงเป็นสามขาหรือมีไฟ ต้องใช้ผังของรุ่นนั้น ห้ามใช้ตารางสองขานี้เดาขา

ตรวจ continuity แยกทีละทาง: ขั้วบวกต้องผ่านฟิวส์ XT30 และสวิตช์จึงถึง W1 ส่วนขั้วลบถึง W2 โดยไม่ผ่านสวิตช์ จากนั้นใส่ถ่านชั่วคราว วัดแรงดัน XT30 ฝั่งแบตตามเครื่องหมาย + / - ต้องได้เครื่องหมายบวกและใกล้แรงดันแพ็ก 2S ถอดถ่านก่อนทำขั้นต่อไป

## 7. ขั้นที่ 3: แยกไฟจาก BUS ไปสามกิ่ง

| เลขสาย | จาก | ไป | สาย/วิธี |
|---|---|---|---|
| P07 | W1 ช่อง 2 | LM2596 IN+ | แดง 20AWG |
| P08 | W2 ช่อง 2 | LM2596 IN- | ดำ 20AWG |
| P09 | W1 ช่อง 3 | TB6612 VM | แดง 20AWG; ฝั่ง TB บัดกรีหรือขั้วกำลังที่ยึดแน่น |
| P10 | W2 ช่อง 3 | TB6612 GND | ดำ 20AWG; ไม่ใช้ Dupont หลวมเป็นสายกำลัง |
| P11 | W1 ช่อง 4 | UBEC IN+ | แดง 20AWG หรือสายเดิมของ UBEC ที่เหมาะสม |
| P12 | W2 ช่อง 4 | UBEC IN- | ดำ 20AWG หรือสายเดิมของ UBEC ที่เหมาะสม |

ทั้งสามตัวรับไฟจาก BUS แบบขนาน ไม่มีลำดับ UBEC → LM2596 → TB

ยังไม่ต่อโหลดฝั่ง OUT ของ LM/UBEC และยังไม่ต่อมอเตอร์ ทดสอบเปิดไฟเพื่อปรับ LM2596 OUT เป็น 5.00V และตรวจ UBEC OUT เป็น 5.0V ตามสวิตช์เลือก/คู่มือรุ่นจริง จากนั้นปิดและถอดไฟก่อนเดินสายต่อ

UBEC ต้องระบุรับแบต 2S ครอบคลุมช่วงที่ใช้ประมาณ 6.0–8.4V หากเป็นรุ่นเลือก 5/6V ให้เลือก 5V ก่อนต่อเซอร์โว เก็บปลาย OUT+ และ OUT- แยกหุ้มฉนวนไว้ในรอบล้อ+จอ+กล้อง

## 8. ขั้นที่ 4: รางไฟควบคุมและ ESP32 บนเบรดบอร์ด

### ตำแหน่งบอร์ด

คร่อมร่องกลางเบรดบอร์ดให้ขาสองแถวอยู่คนละฝั่งร่อง วางตำแหน่งที่เหลือรูเสียบสายเข้าถึงทุกขาที่ใช้ได้

- หากมีพื้นที่เหลือ 2 รูข้างหนึ่งและ 1 รูอีกข้าง แนะนำเผื่อ 2 รูฝั่ง GPIO25/26/27/32/33/14 เพื่อจัดสายมอเตอร์สะดวก
- ฝั่ง GPIO18/23/5/2/4 เหลือ 1 รูได้
- นี่เป็นการจัดพื้นที่ ไม่ใช่ข้อกำหนดทางไฟฟ้า สลับฝั่งก็ได้
- อย่าฝืนขาเพื่อให้ตรงคำแนะนำ ถ้าบอร์ดจริงกว้างจนไม่มีรูว่าง ให้ใช้ฐานต่อขาหรือเบรดบอร์ดแยกที่เหมาะสม
- รูห้าแห่ง a–e ในแถวเดียวกันมักเชื่อมกัน และ f–j เชื่อมกันแยกอีกฝั่ง ตรวจเบรดบอร์ดจริงด้วยมิเตอร์ก่อนใช้
- รางไฟยาวบางรุ่นขาดกลาง ต้องวัดตรวจ ไม่ถือว่าสีเส้นแดง/น้ำเงินรับประกันการเชื่อมต่อ

### สายไฟควบคุม

เดินไฟหลักให้ ESP32 และกล้องจาก WAGO โดยตรง เพื่อลดภาระหน้าสัมผัสรางเบรดบอร์ด

| เลขสาย | จาก | ไป |
|---|---|---|
| L01 | LM2596 OUT+ | W3 ช่อง 1 |
| L02 | LM2596 OUT- | W4 ช่อง 1 |
| L03 | W3 ช่อง 2 | ESP32 VIN/V5/5V ตามตัวอักษรจริง |
| L04 | W4 ช่อง 2 | ESP32 GND |
| L05 | W4 ช่อง 4 | ราง GND เบรดบอร์ด |
| L06 | ESP32 3V3 | แถวว่างแจกไฟ ติดป้าย 3V3 |

L01/L02 ใช้ 20AWG ส่วนหัวเข้าบอร์ดต้องยึดแน่นและรองรับกระแสของบอร์ด ไม่ฝืนสายใหญ่เข้ารูเบรดบอร์ด

ห้ามต่อไฟแบต RAW+ เข้าราง 5V/3V3 และห้ามต่อ 5V เข้าขา 3V3 ของ ESP32 ถ้าแถวแจก 3V3 ไม่พอ ให้ใช้แถวที่สองและจัมเปอร์เชื่อมเฉพาะสองแถวนั้น เขียนป้ายกำกับชัดเจน

## 9. ขั้นที่ 5: TB6612 และมอเตอร์

สาย VM/GND กำลังต่อไว้ใน P09/P10 แล้ว ไม่ต้องลากกระแสมอเตอร์ผ่านเบรดบอร์ด

| เลขสาย | จาก | ไป |
|---|---|---|
| M01 | แถว 3V3 จาก ESP32 | TB VCC |
| M02 | แถว 3V3 จาก ESP32 | TB STBY |
| M03 | ESP32 GPIO25 | TB PWMA |
| M04 | ESP32 GPIO26 | TB AIN1 |
| M05 | ESP32 GPIO27 | TB AIN2 |
| M06 | ESP32 GPIO32 | TB PWMB |
| M07 | ESP32 GPIO33 | TB BIN1 |
| M08 | ESP32 GPIO14 | TB BIN2 |
| M09 | TB AO1 | ขั้วขับมอเตอร์ซ้ายเส้นที่ 1 |
| M10 | TB AO2 | ขั้วขับมอเตอร์ซ้ายเส้นที่ 2 |
| M11 | TB BO1 | ขั้วขับมอเตอร์ขวาเส้นที่ 1 |
| M12 | TB BO2 | ขั้วขับมอเตอร์ขวาเส้นที่ 2 |

M01–M08 เป็นสายลอจิก ใช้ Dupont ที่แน่นได้ M09–M12 ใช้สายกำลัง 20AWG และขั้ว/รอยบัดกรีที่เหมาะสม

**จั๊ม STBY กับ VCC เข้าด้วยกันแล้วลากเส้นเดียวไปแถว 3V3 ทำได้** ประหยัดสายไปหนึ่งเส้นและไม่เสียขา GPIO
เงื่อนไขเดียวคือคู่ที่จั๊มไว้ต้องไปรับ **3.3V เท่านั้น** ห้ามไปรับ 5V หรือแรงดันแบต
ผลของการจั๊มคือไดรเวอร์ตื่นตลอดเวลาที่มีไฟ จึงต้องพึ่ง pull-down ในชิปกับการตั้งขาเป็น LOW ตอน `setup()`
เพื่อไม่ให้ล้อกระตุกตอนบูต ถ้าภายหลังอยากสั่งตัดไดรเวอร์จากโค้ด ค่อยแยก STBY ออกไปเข้า GPIO ว่างตัวหนึ่ง

มอเตอร์จริงในเอกสารเดิมคือ TT Encoder 1:90 6V 175RPM สองตัว ต้องแยกสายขับมอเตอร์สองเส้นจากสาย Encoder VCC/GND/A/B ห้ามเดาจากสี รอบนี้ยังไม่ต่อ Encoder ให้หุ้มปลายแยกกัน

ผังเดิมให้ VM รับแบต 2S โดยตรง จึงมีพัลส์แรงดันถึง 8.4V ตอนแบตเต็ม แม้ใช้ PWM ต่ำ การจำกัด PWM ไม่ใช่ตัวลดแรงดัน 6V และไม่ป้องกันความร้อนตอนล้อล็อก ใช้ทดสอบช่วงสั้น ยกล้อพ้นพื้น เริ่ม 80–100/255 และไม่เกิน 180/255 ตามแผนเดิม พร้อมวัดกระแส/ตรวจความร้อนก่อนทดลองรับน้ำหนักจริง ไม่อ้างว่ามอเตอร์รับการใช้งานแบบนี้ได้ทุกสภาวะ

หากข้างใดหมุนกลับทิศ ให้ปิดและถอดไฟแล้วสลับสาย AO1/AO2 หรือ BO1/BO2 ของข้างนั้นเท่านั้น

## 10. ขั้นที่ 6: จอ TFT ST7789

ชื่อขาที่บันทึกจากจอเดิม: VCC GND CS RESET DC SDI SCK LED SDO และกลุ่ม T_CLK T_CS T_DIN T_DO T_IRQ

| เลขสาย | จาก | ไป |
|---|---|---|
| D01 | แถว 3V3 | TFT VCC เพื่อเริ่มทดสอบ |
| D02 | ราง GND เบรดบอร์ด | TFT GND |
| D03 | ESP32 GPIO5 | TFT CS |
| D04 | ESP32 GPIO4 | TFT RESET/RST |
| D05 | ESP32 GPIO2 | TFT DC/RS |
| D06 | ESP32 GPIO23 | TFT SDI/MOSI |
| D07 | ESP32 GPIO18 | TFT SCK/CLK |
| D08 | แถว 3V3 ผ่านตัวต้านทาน 100Ω สำหรับเริ่มทดสอบ | TFT LED/BL |

D08 ใช้แนวทางเริ่มทดสอบจากเอกสารเดิม เมื่อยังไม่ยืนยันวงจร LED บนโมดูล ภาพอาจสว่างน้อย ต้องตรวจวงจรจริงก่อนลด/ถอดตัวต้านทาน หากยืนยันว่ามีตัวจำกัดกระแสหรือวงจรขับรองรับแล้ว จึงต่อไฟตามสเปกโมดูล ไม่จ่าย LED จาก GPIO ตรง

- SDO/MISO ไม่ต่อ และตั้ง TFT MISO เป็น -1
- กลุ่มขาสัมผัส T_CLK/T_CS/T_DIN/T_DO/T_IRQ และขา SD ยังไม่ต่อ
- เริ่ม VCC ที่ 3.3V หากจอไม่ขึ้น อย่าเปลี่ยนเป็น 5V ทันที ให้ตรวจ driver สาย และสเปกวงจร VCC ก่อน ชิปจอ ST7789 อย่างเดียวไม่ยืนยันว่าโมดูลรับ VCC 5V ได้
- TFT ใช้ SPI SCLK=18, MOSI=23, CS=5, DC=2, RST=4 และตั้ง ST7789 240×320 ตามเอกสารเดิม หมุนแนวนอนในโค้ดตามการติดตั้ง
- ถ้าอัปโหลด ESP32 ไม่เข้า ขา GPIO2 เป็นขาบูตที่ต้องระวัง ลองถอดสาย DC ชั่วคราวระหว่างแฟลชตามแผนเดิม

## 11. ขั้นที่ 7: กล้อง XIAO ESP32S3 Sense

กล้องติดกับชุด Sense ของ XIAO ไม่ต้องลากสายภาพจากกล้องเข้าบอร์ด ESP32 หลัก ในระบบนี้ XIAO ประมวลผลแล้วส่งข้อความผลลัพธ์ผ่าน UART หนึ่งเส้น

### ทางจ่ายไฟที่ปรับจากเอกสารเดิม

คู่มือ Seeed ระบุให้มีไดโอดระหว่างแหล่งจ่ายภายนอกกับขา 5V ของ XIAO: anode หันหาแหล่งจ่าย cathode หันหาขา 5V ใช้ Schottky ที่พิกัดกระแสเพียงพอสำหรับกล้องและทดสอบแรงดันหลังไดโอดภายใต้โหลด ห้ามใช้ไดโอดสัญญาณกระแสต่ำที่ไม่ทราบพิกัด

```text
W3 LOGIC 5V → ขา Anode ของไดโอด → ขา Cathode → XIAO 5V
                                    แถบบนตัวไดโอดทั่วไปอยู่ฝั่ง Cathode
W4 GND ─────────────────────────────────────→ XIAO GND
XIAO D6 / GPIO43 / TX ──────────────────────→ ESP32 GPIO16 / RX2
```

| เลขสาย | จาก | ไป |
|---|---|---|
| C01 | W3 ช่อง 3 | ไดโอด ขา Anode |
| C02 | ไดโอด ขา Cathode | XIAO 5V |
| C03 | W4 ช่อง 3 | XIAO GND |
| C04 | XIAO D6 / GPIO43 / TX | ESP32 GPIO16 / RX2 |

- หุ้มรอยต่อไดโอดทั้งสองด้าน ตรวจขั้วตาม datasheet ของตัวจริง
- หลังไดโอดแรงดันจะต่ำกว่า LM2596 5.00V ให้ทดสอบการเริ่มกล้องและ Wi-Fi จริง อย่าเพิ่ม LM2596 เกิน 5V เพื่อชดเชย เพราะกิ่งเดียวกันเลี้ยง ESP32 ด้วย
- XIAO 3V3 ไม่ต่อรวมกับ ESP32 3V3
- XIAO D7/RX ไม่ต้องต่อสำหรับการส่งข้อมูลทางเดียว
- เฟิร์มแวร์เดิมกำหนด 9600 baud ฝั่ง XIAO ต้องส่งผ่าน UART ที่กำหนด TX เป็น D6/GPIO43 จริง ไม่ใช่เพียงพิมพ์ข้อความออก USB Serial
- ฝั่ง ESP32 ต้องรับที่ GPIO16 และไม่เปิด TX บนขาที่สงวนให้ส่วนอื่น
- เปิดทั้งสองบอร์ดก่อนส่งข้อมูล หลีกเลี่ยงส่ง UART เข้าอีกบอร์ดที่ยังไม่มีไฟ

อ้างอิง [คู่มือ XIAO ESP32-S3 ของ Seeed](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)

### ถ้ายังไม่มีไดโอด

ทดสอบ XIAO ผ่านพอร์ต USB-C ของมันก่อน โดยไม่ต่อ C01/C02 และต่อเฉพาะ C03 GND ร่วม กับ C04 TX→RX เมื่อทั้งสองบอร์ดมีไฟแล้ว วิธีนี้ใช้ทดสอบกล้องและ UART ได้ แต่ยังไม่ถือว่าจ่ายไฟทั้งหุ่นด้วยแบตเส้นเดียวเสร็จ

ระหว่างแฟลช/ทดสอบผ่าน USB ให้ถอดสายไฟ 5V ภายนอกของบอร์ดที่เสียบ USB และจัดให้ไม่มีแหล่ง 5V สองทางชนกัน สำหรับแฟลชแยกบอร์ดให้ถอดสายสัญญาณข้ามบอร์ดที่ยังไม่มีไฟด้วย

## 12. UBEC เตรียมไว้และต่อเซอร์โวในอนาคต

งานรอบนี้ต่อ P11/P12 ได้ แล้วหุ้มปลาย OUT ของ UBEC แยกไว้ ไม่จำเป็นต้องใช้ UBEC เลี้ยงล้อ จอ หรือกล้อง

เมื่อจะเริ่มเซอร์โว:

| จาก | ไป |
|---|---|
| UBEC OUT+ ที่วัดได้ 5.0V | PCA9685 ขั้วสกรู V+ |
| UBEC OUT- | PCA9685 ขั้วสกรู GND |
| ESP32 3V3 | PCA9685 VCC ฝั่งลอจิก |
| GND ร่วม | PCA9685 GND ฝั่งลอจิก |
| ESP32 GPIO21 | PCA9685 SDA |
| ESP32 GPIO22 | PCA9685 SCL |

V+ เป็นไฟกำลังเซอร์โว ส่วน VCC เป็นไฟลอจิก ไม่ใช่ขาเดียวกัน การต่อเซอร์โวจริงและ OE/ช่อง CH ให้ใช้แผน PCA9685 เดิมเพิ่มเติม รอบนี้ยังไม่สั่งเซอร์โวและยังไม่รับรองสายหลัก 20AWG สำหรับโหลดรวม

## 13. จุดวัดและลำดับเปิดทดสอบ

ใช้มัลติมิเตอร์โหมด DC voltage สำหรับตารางนี้ ห้ามเสียบสายมิเตอร์ช่องวัดกระแสแล้วคร่อมแบตหรือ BUS

| จุดวัด แดง / ดำ | ค่าหรือเงื่อนไขที่ต้องตรวจ |
|---|---|
| BMS P+ / P- | ใกล้แรงดันแพ็ก 2S; หาก 0V ต้องตรวจ BMS ไม่ข้าม BMS |
| XT30 ฝั่งแบต + / - | ใกล้แรงดัน P+/P- และมิเตอร์แสดงขั้วถูก |
| W1 / W2 เมื่อเปิดสวิตช์ | ใกล้แรงดันแพ็ก |
| W1 / W2 เมื่อปิดสวิตช์ | ไม่รับไฟใหม่จากแบต; อาจมีแรงดันค้างจากคาปาซิเตอร์ชั่วครู่ |
| W3 / W4 | ตั้ง 5.00V ไม่มีโหลด แล้ววัดซ้ำขณะกล้อง/Wi-Fi และมอเตอร์ทำงาน |
| ESP32 3V3 / GND | ใกล้ 3.3V |
| UBEC OUT+ / OUT- | ใกล้ 5.0V ก่อนต่อ PCA9685 |
| XIAO 5V / GND | เป็น 5V หักแรงดันตกไดโอด ต้องทำงานเสถียรภายใต้โหลดจริง |
| TB VCC และ STBY / GND | ใกล้ 3.3V |
| TB VM / GND | ใกล้แรงดัน W1/W2 ไม่ใช่ 5V จาก LM |

ลำดับทดสอบ โดยปิดและถอดแหล่งจ่ายก่อนเปลี่ยนสายทุกขั้น:

1. ตรวจรอยบัดกรี ขั้วคาปาซิเตอร์ และไม่มีชอร์ตค้าง ตรวจพิกัดสาย/ฟิวส์ก่อนจ่ายไฟ
2. ทดสอบเฉพาะแบต BMS ฟิวส์ XT30 สวิตช์ W1/W2
3. ต่ออินพุต LM และ UBEC โดยไม่มีโหลด ตั้ง/วัดเอาต์พุต
4. ต่อ ESP32 อย่างเดียว ตรวจเริ่มทำงานและแรงดัน
5. ต่อ TFT ตรวจภาพและแสง โดยใช้เฟิร์มแวร์ pin map นี้
6. ทดสอบ XIAO แยกให้กล้องเริ่มได้ แล้วต่อ GND และ UART ตรวจว่ารับข้อความจริง
7. ต่อ TB VCC/STBY และหกขาควบคุม โดยยังไม่ต่อมอเตอร์ สั่งค่าเริ่มต้นหยุด
8. ยกล้อพ้นพื้น ต่อมอเตอร์ซ้ายทดสอบสั้น ๆ แล้วทำกับขวา
9. ทดสอบสองล้อพร้อมจอและกล้อง เริ่มความเร็วต่ำ ตรวจว่า ESP32/XIAO ไม่รีเซ็ต
10. วัดแรงดันตกและตรวจความร้อนที่สายหลัก รางถ่าน ฟิวส์ XT30 สวิตช์ WAGO LM และ TB ก่อนทดลองวิ่งบนพื้น
11. หยุดเมื่อมีสาย/ขั้วร้อนผิดปกติ กลิ่นไหม้ ล้อค้าง ไฟตก รีบูต หรือฟิวส์ขาด หาสาเหตุก่อนเพิ่มโหลด
12. สำหรับต้นแบบนี้ ใช้เส้นหยุดแบตตามแผนเดิมประมาณ 7.0V ขณะใช้งาน และหยุดก่อนหน้านั้นหากราง 5V ยุบจนระบบไม่เสถียร ไม่รอ BMS ตัด

## 14. สรุป pin map และการถอดชุดสาย

| กลุ่ม | การต่อ |
|---|---|
| มอเตอร์ซ้าย | PWMA=25, AIN1=26, AIN2=27 |
| มอเตอร์ขวา | PWMB=32, BIN1=33, BIN2=14 |
| TB ลอจิก | VCC=3V3, STBY=3V3 |
| TFT | SCK=18, MOSI=23, CS=5, DC=2, RESET=4, MISO ไม่ต่อ |
| กล้อง | XIAO D6/GPIO43 TX → ESP32 GPIO16 RX2, 9600 baud |
| I2C สำรองเซอร์โว | SDA=21, SCL=22 |
| Encoder / Touch / เซนเซอร์อื่น | ยังไม่ต่อในคู่มือนี้ |

ติดป้ายเลขสายทั้งสองปลายตามตาราง เช่น P09 / TB-VM, D06 / TFT-SDI, C04 / CAM-TX

- ถอดแบต: ปิดสวิตช์ ถอด USB แล้วแยก XT30 ชุดแบต BMS และฟิวส์ออกพร้อมกัน
- ถอดกล้อง: ปิด/ถอดไฟ แล้วถอดชุด C02/C03/C04 ฝั่ง XIAO
- ถอดจอ: ปิด/ถอดไฟ แล้วถอด D01–D08 เป็นชุด
- ถอดชุดล้อ: ปิด/ถอดไฟ แล้วถอดสายควบคุมและคลาย VM/GND จาก WAGO ห้ามดึงที่รอยบัดกรี
- ปลาย WAGO ยกคันโยกก่อนดึง ไม่กระชากสายออกทั้งที่คันโยกปิด

## 15. สิ่งที่คู่มือนี้แก้จากคำตอบ/เอกสารก่อนหน้า

1. ระบุ XT30 หลังฟิวส์และก่อนสวิตช์ เพื่อให้ถอดแบตพร้อม BMS และฟิวส์ได้
2. เปลี่ยนคำว่า BUS ที่กว้าง ๆ เป็น WAGO W1–W4 พร้อมระบุช่องและเลขสาย
3. แยกไฟเข้า UBEC เป็นอีกกิ่งหนึ่ง ต่อเตรียมได้ แม้ยังไม่ใช้เซอร์โว
4. รวม XIAO พร้อมทางจ่ายไฟผ่านไดโอดตามคู่มือผู้ผลิต ซึ่งเอกสารเก่าเขียน 5V ตรงไว้
5. ไม่ใช้ค่ากระแสรวมต่ำกว่า 0.5A จากเอกสารต้นแบบเดิมเป็นข้อรับรองของชุดที่รวมกล้อง
6. ไม่รับรองฟิวส์ 7.5A กับสาย 20AWG ที่ยังไม่ทราบสเปก
7. ยืนยัน pin map ใหม่ ส่วนผังเก่าในรายชื่ออุปกรณ์ไม่ใช้ต่อสายรอบนี้
8. ระบุแรงดันจอและวงจร LED เป็นจุดที่ยังต้องยืนยัน ไม่อ้างว่าฮาร์ดแวร์ทุกจุดถูกตรวจแล้ว
