## สูตร (บังคับใช้ตามนี้ — คานยื่นหน้าตัดสี่เหลี่ยมคงที่ จาก Bayer/Covestro Snap-Fit Joints design guide)
ตัวแปร: t = ความหนาขาในทิศที่งอ (mm) · b = ความกว้างขาตั้งฉากทิศงอ (mm; ชิ้นของเราขาวางแนวนอนงอใน XY จึง b = ความสูงขาแนว Z) · L = ความยาวขาจากโคนถึงปาก (mm) · y = ระยะปากเกี่ยว/ระยะที่ขาต้องงอ (mm) · E = โมดูลัส (MPa) · μ = สัมประสิทธิ์แรงเสียดทาน · α = มุมนำเข้า (องศา) · α′ = มุมถอด (องศา)
1. ความเครียดสูงสุดที่โคน: ε = 1.5 · t · y / L²
2. แรงงอขา: P = b · t² · E · ε / (6 · L) (N)
3. แรงกดใส่: W = P · (μ + tan α) / (1 − μ · tan α)
4. แรงดึงถอด: W′ = P · (μ + tan α′) / (1 − μ · tan α′) · ถ้า 1 − μ·tan α′ ≤ 0 ให้แสดง "ล็อกตาย (ถอดไม่ได้ถ้าไม่ง้าง)" แทนตัวเลข
5. ค่าปลอดภัย = ε_ยอมรับได้ / ε · เขียว ≥ 1.5, เหลือง 1.0–1.5, แดง < 1.0
- แสดงสูตรและแทนค่าให้เห็นทุกบรรทัด (ให้ใช้ในเล่มได้) · แสดงผลทั้ง N และ kgf (÷ 9.81)
