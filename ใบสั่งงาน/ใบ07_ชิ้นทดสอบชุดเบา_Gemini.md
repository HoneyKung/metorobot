# ใบ 07 — ชิ้นทดสอบชุดเบา (เขียนใหม่ทั้งหมด) · ผู้เขียน Gemini · หัวงาน Claude ตรวจ · 2 พ.ย. 2569

คำเจ้าของ (คำต่อคำ): "ไฟล์มีชิ้นลอยเต็มไปหมด พวกเลข และชุดสามหนึ่งเปลือง + ช้าตรง กำแพงหนาไปสำหับทดสอบ และมีป้ายชื่อเนี่ยแหละทำให้เสียเวลาทดสอบมากๆ ฉันจำตัวแหน่งได้เองอยุแล้ว พอปริ้นเสร็จก็จะเอามาคเกอร์มาคไว้ ไม่ควรทำให้สะดวกถ้ามันทำให้เวลาเราลดลง" · "หัว0..4 พิมพวกตัวอักษรไม่ติดหรอก"

อ่าน/เขียนด้วย file tool เท่านั้น ห้ามใช้ shell · เขียนไฟล์เดียว `out/meto_fit_lite.scad` (OpenSCAD 2021.01) ตัวแปรบนสุด + `part = "..."` เลือกชิ้น · หัวงาน export และตรวจด้วยสคริปต์ (ชิ้นลอย / ชั้นว่าง / ผิวคว่ำต้องซัพพอร์ต) เอง
ไฟล์เดิมใน `ref/` (meto_fit_tests*.scad) ใช้เป็นที่มาของ **ขนาดและค่าเผื่อเท่านั้น** ห้ามคัดลอกป้าย/ตัวเลข/ขีดสเกล

## กฎบังคับทุกชิ้น
1. **ห้ามมีตัวอักษร ตัวเลข ป้าย ขีดสเกล** ใด ๆ
2. ผนัง 1.2 mm · ความสูงต่ำสุดที่ยังทดสอบได้ (กรอบบอร์ด 4 mm) · พื้นถาด 1.0 mm หรือไม่มีพื้น (กรอบวงแหวนวางบนเตียง) ถ้าทดสอบได้
3. **ทุกส่วนต่อเนื่องจากเตียงขึ้นมา**: ห้ามมีเกาะที่เริ่มกลางอากาศ ห้ามชั้นว่าง · ผิวหันลงต้อง ≥45° · รูแนวนอนใช้หลังคาหยดน้ำ/45°
4. ทุก union ต้องซ้อนทับ ≥0.05 mm (ห้ามแตะแค่ผิว)
5. ทดสอบเฉพาะจุดที่ต้องรู้ ไม่ทำของทั้งชิ้น

## ชิ้น (part)
- `pca_ring_020` / `pca_ring_035` / `pca_ring_050`: วงแหวนรอบบอร์ด PCA9685 62.23×25.4 + เผื่อ 0.35/ด้าน, ไม่มีพื้น, สูง 4, ครีบ 2 ต่อด้านยาว 1 ต่อด้านสั้น (ยื่น 0.20/0.35/0.50), เว้นช่องหัวพินปลายบอร์ด
- `hw_rings`: วงแหวนแบบเดียวกัน (ครีบ 0.35) ในชิ้นเดียว เชื่อมด้วยแถบบาง: LM2596 43×21, TB6612 20×20 (+ช่องข้างสำหรับตัวเก็บประจุ Ø10), BMS 47×23, CM620 30×17, รางถ่าน 76×41, HW-201 32×14 · ค่าเอกสารใน ref
- `wheel_bore`: วงแหวน OD 12 สูง 5 มีรูเพลา TT (รัศมี 2.753 ตัดแบน ±1.899 ตามที่ Luna วัดไว้ใน set2) 2 วง: +0.0 และ +0.1 บนแถบเชื่อม
- `rod_rings`: วงแหวนสูง 5 รูเกลียว M6 6.4/6.6 และ M8 8.4/8.6 ผนัง 3 บนแถบเชื่อม
- `buckle_flat`: หัวเข็มขัดล็อกชั้น — ตัวผู้วางแบน (ขา t 1.2 ยาว 20) + ตัวเมียเป็นบล็อกเตี้ยวางแบน ใช้ทดสอบกดล็อก/บีบปลด ไม่ต้องมีท่อนผนังชั้น
- `wago_low`: ถาด WAGO 221-415 + 221-413 ราวสูง 3 ครีบ 0.35 ไม่มีอะไรลอย
- `caster_lite`: เบ้าลูกล้อ Ø12 แบบพิมพ์ตั้ง ปากล็อกด้วยนิ้วงอ 4 นิ้ว หนา ≥0.8 ด้านในเอียง 45° (ไม่ต้องซัพพอร์ต) + ลูก Ø12 แบ่ง 2 ซีกวางแบน + หมุดต่อ
- `ir_bracket`: ที่ยึด HW-201 แบบแผ่น L ง่าย ๆ (แผ่นตั้งมีช่องใส่บอร์ด + รูไขควงตรงตัวปรับ) พิมพ์ตะแคงให้ไม่ต้องซัพพอร์ต
