## งาน B — เฟิร์มแวร์: สวิตช์ไอเดิลออนไลน์ + ทิศแขน + ตรวจครบ

```
ไฟล์ RoboPCA9685/RoboPCA9685.ino (+ meto_emotes.h) แฟลช ~98% เหลือ ~25 KB เพิ่มโค้ดให้น้อยที่สุด
คอมไพล์: "%LOCALAPPDATA%/Programs/Arduino IDE/resources/app/lib/backend/resources/arduino-cli.exe" compile --config-file "%USERPROFILE%/.arduinoIDE/arduino-cli.yaml" -b esp32:esp32:esp32 <สำเนาในโฟลเดอร์ชื่อ RoboPCA9685 ใน %TEMP%>
1) เพิ่มสวิตช์ปิด/เปิดท่าไอเดิล (idleTick) สั่งได้ทั้ง Serial และเว็บ: ใช้ช่องทางคำสั่งเว็บที่มีอยู่ (HTTP endpoint ของ WebServer / คำสั่งบรรทัด "!...") เพิ่ม "!idle 0" / "!idle 1" และให้ /state รายงาน idleOn · ค่าเริ่ม = เปิด · ถ้ามีหน้าเว็บควบคุมหุ่น (server.py / templates / static) เพิ่มปุ่มเปิด/ปิดไอเดิล
2) ตรวจทิศแขน MG996R: cfg.armDir ซ้าย −1 ขวา +1 (~บรรทัด 653) เทียบการติดตั้งจริง (MG996R ซ้ายอยู่ −X ขวาอยู่ +X หุ่นหันหน้า +Y เฟืองชี้ออกข้าง) ให้ "ยก + = ขึ้น" ถ้าถูกแล้วไม่ต้องแก้ ถ้าตัดสินไม่ได้ บอกวิธีเช็กด้วยปุ่ม r/t ใน Serial
3) ตรวจครบ: มือขวาย้ายเป็น CH6 แล้ว (SERVO_HAND_RIGHT_CH=6) ห้ามมีที่อ้างช่อง 3 ตรง ๆ · กล้อง Serial2 RX23 (F/P/O) · กันตก · เบรกนุ่ม · ไอเดิล · ท่าอารมณ์ · คอมไพล์ผ่าน
รายงาน: แก้อะไร คอมไพล์กี่ % คำสั่งที่เว็บต้องส่ง
```
