# สเปคภาพ Sprite หุ่น METO — ชุด Top View + จอหน้า (วาดใหม่ 22 ภาพ)

> **เปลี่ยนแนวทางจากเดิม (30 ก.ค. 2026):** เลิกใช้มุมข้าง/หน้า/หลัง → เวทีจำลองเป็น **มุมมองด้านบน (top view)**
> เพราะมุมบนบอก "ตำแหน่ง + ทิศทาง + การเลี้ยว" ได้ตรงความจริงที่สุด และ**หมุนภาพเดียวได้ทุกทิศ** → วาดน้อยลงกว่าครึ่ง
> ส่วน "หน้าหุ่น" ย้ายไปอยู่ **จอที่ 2 (จอหน้าหุ่น)** ซึ่งเป็น digital twin ของจอ TFT บนหุ่นจริง

**สรุป: วาดใหม่แค่ 22 ภาพ** (เดิม 62 ภาพ) — จอหน้าหุ่นวาดด้วยโค้ดให้แล้ว ไม่ต้องวาดภาพ

## กติกาการวาดชุด top/ (อ่านก่อนวาด!)

1. **ผืน canvas เป็นสี่เหลี่ยมจัตุรัส 640 × 640 px ทุกภาพ**
   (จัตุรัสเพราะโค้ดหมุนภาพรอบจุดกลางผืน — ผืน 4:3 จะหมุนแล้วขอบขาด)
2. **หุ่นหันขึ้น (12 นาฬิกา) เสมอ** — ทิศ "เดินหน้า" ชี้ขึ้นด้านบนของผืนภาพ
   โค้ดจะหมุนภาพทั้งชุดเองเมื่อหุ่นเลี้ยว (หมุนลื่นไหลแบบ smooth ด้วย)
3. **จุดกลางผืนภาพ (320, 320) = จุดหมุนของหุ่น = จุดคอ (จุดหมุนหัว)**
   วาดให้ศูนย์กลางตัวหุ่น/คอ อยู่ตรงกลางผืนเป๊ะ ทุกชิ้น ทุกภาพ
4. **วางชิ้นส่วนตรงตำแหน่งจริงบนตัวหุ่น** ส่วนที่เหลือปล่อยโปร่งใส
   → โค้ดวางทุกภาพทับกันที่จุดกลาง ประกอบร่างได้เลย ไม่ต้องจูนพิกัดรายชิ้น
   → เคล็ดลับ: วาดทุกชิ้นในไฟล์เดียว (คนละเลเยอร์) แล้ว export ทีละเลเยอร์
5. **PNG พื้นโปร่งใส** เท่านั้น
6. **ขนาดหุ่นบนผืน:** ฐาน+ตีนตะขาบกว้างประมาณ **300 px**, กางแขนสุดไม่เกิน **520 px**
   (โค้ดย่อด้วย `SPRITE_SCALE` ใน robot-sim.js — ปรับได้ถ้ารู้สึกใหญ่/เล็กเกิน)
7. **จุดไหล่ของภาพแขนทุกท่าอยู่ตำแหน่งเดิมเสมอ** (โค้ดไม่หมุนแขนให้ — ทุกท่าวาดจริง)
8. **หัวมองจากบน** ให้เห็นขอบจอ TFT ที่ด้านหน้า (ด้านบนของผืน) เป็นแถบ — คนดูจะรู้ว่าหน้าหันทางไหน
9. ตั้งชื่อไฟล์ตามรายการด้านล่าง**เป๊ะๆ** (ตัวพิมพ์ใหญ่-เล็กตรงตามนี้)

## ลำดับการซ้อนชั้น (ล่าง → บน)

`Base (ฐาน+ตีนตะขาบ) → ArmLeft → ArmRight → Head`

มองจากบน: หัวสูงสุดจึงอยู่หน้าสุด, แขนอยู่เหนือฐานแต่ต่ำกว่าหัว

## ตารางคู่ผสมแขน+มือ (9 ท่าต่อแขน 1 ข้าง)

ท่าแขน 3 (`Close` หุบแนบตัว / `Normal` กลาง / `Open` กางออก) × ท่ามือ 3 (`Down` ลง / `Center` กลาง / `Up` ขึ้น)

- **ท่าแขน** = กางออกด้านข้างมากน้อย → **มองจากบนเห็นชัดเจน** (มุมกาง ~15° / ~55° / ~95° จากแนวหน้า)
- **ท่ามือ** = สูง-ต่ำ ซึ่งมองจากบนเห็นเป็น **ความยาวที่หดสั้นลง (foreshortening)**
  - `Center` (แขนขนานพื้น) = ยาวสุด เห็นเต็มลำ
  - `Down` (ปลายแขนชี้ลงพื้น) = สั้นลง เห็นมือเล็กลง + มีเงาใต้แขน
  - `Up` (ปลายแขนชี้ขึ้น) = สั้นลง แต่ **มือใหญ่ขึ้น** (ใกล้กล้องด้านบน) และควรวาดสว่างกว่า

ชื่อไฟล์ = `top_{แขนข้างไหน}_{ท่าแขน}_{ท่ามือ}.png`

> ⚠️ **ซ้าย/ขวายึดมุมมองของหุ่น** (ไม่ใช่ของคนดู) — มองจากบนโดยหุ่นหันขึ้น:
> แขน**ซ้าย**ของหุ่นอยู่ฝั่ง**ซ้าย**ของผืนภาพ, แขน**ขวา**อยู่ฝั่ง**ขวา** (ตรงกับที่เห็น)

**ลำดับแนะนำในการวาด (ทยอยได้ เว็บทำงานตลอด):**
1. `top_Base.png` + `top_Head_Center.png` + `top_ArmLeft_Normal_Center.png` + `top_ArmRight_Normal_Center.png`
   → 4 ภาพ เห็นหุ่นท่า default บนเวทีแล้ว
2. เติมท่าแขนที่ใช้บ่อย → ปิดท้ายด้วยหัวหันซ้าย/ขวา
3. **ชิ้นไหนยังไม่มีภาพ ระบบวาดหุ่นด้วยโค้ด (มุมบนเหมือนกัน) ให้อัตโนมัติ** — เว็บไม่พังระหว่างวาด

## 🖥 จอที่ 2 — จอหน้าหุ่น (Face Screen)

จอนี้เป็น **digital twin ของจอ TFT บนหุ่นจริง**: ขนาด 320 × 240 เท่าจอจริงเป๊ะ
โค้ดใน `robot-sim.js` **port ฟังก์ชัน `drawEyes_*` มาจาก `Robo/Robo.ino` แบบ 1:1**
(ค่าพิกัดตา `EYE_L_X=80, EYE_R_X=240, EYE_Y=110` และรัศมีทุกค่าตรงกับเฟิร์มแวร์)

**จึงไม่ต้องวาดภาพหน้า** — และได้ของแถมที่ภาพนิ่งทำไม่ได้:
กระพริบตา 3 แพทเทิร์น, เหลือบมองซ้าย-ขวา, ถอนหายใจ, หัวใจเต้น (โหมด Love) — จังหวะเวลา (ms) เท่าเฟิร์มแวร์

### ถ้าอยากใช้ภาพวาดมือแทน (ไม่บังคับ)

1. วางไฟล์ใน `sprites/face/` **ผืน 320 × 240 px** (เต็มจอ พื้นสีขาวทึบเหมือนจอจริง)
2. เปิดสวิตช์ในโค้ด: `robot-sim.js` → `var USE_FACE_SPRITES = true;`
   (หรือสั่งจาก console ชั่วคราว: `RobotSim.setFaceSprites(true)`)

มีไฟล์ไหน ระบบใช้ภาพนั้นแทนโค้ดเฉพาะเฟรมนั้น (ไม่มีก็ใช้โค้ดวาดต่อ):

| `face_LookLeft.png` `face_LookRight.png` | เหลือบซ้าย / ขวา | ใช้ตอน idle glance ด้วย |
| `face_Happy.png` | ยิ้ม | |

## หมายเหตุสำหรับคนแก้โค้ด

- ชื่อไฟล์/โฟลเดอร์เปลี่ยน → ต้องแก้ `buildSpriteManifest()` ใน `robot-sim.js` และไฟล์นี้พร้อมกัน

- แก้ภาพ: วางทับไฟล์เดิมชื่อเดิม รีเฟรชเว็บเห็นผลทันที
- แก้หน้าหุ่นบนจอที่ 2: แก้ที่ `FaceTwin.frames` ใน `robot-sim.js` **และแก้ `drawEyes_*` ใน `Robo/Robo.ino` ให้ตรงกัน** (ไม่งั้น twin ไม่ตรงของจริง)
